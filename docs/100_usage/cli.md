# 対話する道具と使う

[READMEへ戻る](../../README.md) · [使い方の一覧](README.md)

## Claude Code

apt で導入済みなら、次の準備は不要です。ソースから使う場合は、yadori のリポジトリで一度だけ手元の命令として入れます。

```console
$ uv tool install --editable .
```

次に、普段どおりの Claude Code で定額契約へログインし、付き添わせたい作業場所を一度開いて、そこにある設定や MCP（外の道具へつなぐ仕組み）を信頼するか確認します。そのあと、同じ作業場所で次を実行します。

```console
$ yadori claude
（そら として Claude Code を起こします）
```

これ以降は普段の Claude Code と同じように使います。話しかけるたびに、宿りの名乗り、いまの気持ちと性格、直近の会話、関係する記憶が返事の前提へ自動で渡ります。返事まで終わった一往復だけが記憶され、途中で止めた発話は残りません。

普段の Claude Code からは、AIモデル、見た目、許可、承認済みの MCP、指示とスキルのうち、安全に一回の起動へ写せるものだけを借ります。`CLAUDE.md`、普段の会話履歴、自動記憶、バックグラウンド処理、接続先を変える設定、外部サービス側の連携は借りません。利用者ごとの保存内容や常時動く処理を持つプラグインも借りず、理由を画面へ出します。起動中の履歴と設定は `YADORI_HOME` の一時置き場へ分け、終了時に捨てます。

作業場所の設定がまだ信頼されていない、`.mcp.json` の利用可否が決まっていない、定額契約以外の接続先が選ばれている場合は、何を確かめればよいかを出して起動しません。これは普段の Claude Code 側で内容を確認してから、もう一度 `yadori claude` を実行してください。

## Codex

Codex にログイン済みの端末で、付き添わせたい作業場所から `yadori codex` を実行します。宿りの名乗り、記憶、気持ちは同じ設定を使います。Codex のデスクトップ画面は対象外です。

## agy

Linux では Antigravity CLI 1.2.1 / 1.2.2 に対応しています。追加検索の実入口は 1.2.2 で確認しています。`agy` と `bubblewrap` を導入し、普段の agy で Google アカウントへのログイン、初回案内、作業場所の信頼確認を済ませます。その作業場所で起動します。

```console
$ yadori agy
（そら として agy を起こします）
```

話しかける前に同じ宿りの名乗り・記憶・気持ちが渡り、完成した一往復を記憶します。検索、ファイル編集、端末操作を使え、変更の承認は agy で行います。普段の agy の設定と会話履歴へは書き込みません。

今回は技能・プラグイン・MCP の継承、下位担当・予約・背景作業、会話の再開・分岐・担当切替には対応しません。別の会話へ切り替えようとすると起動を終えます。API キーを使う設定や、対応していない環境では理由を示して起動しません。

文脈を渡せないときは返事を作らず止まります。記憶へ保存できなかった完成済みの往復は回復用の原文を残し、次回の起動前に再試行します。完成状態を確認できない場合は、その記録の場所を示して起動を断ります。原文を確かめる前に回復用の領域を削除しないでください。[設定と履歴の扱い](../010_decisions/ADR-022-agyの設定と履歴をLinuxの起動ごとに分ける.md)に境界を記載しています。
