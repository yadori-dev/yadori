# 対話する道具と使う

[READMEへ戻る](../../README.md) · [使い方の一覧](README.md)

## 普段の環境に宿りを加える

普段の作業場所から `yadori claude`、`yadori codex`、`yadori agy` を実行します。道具本体の設定、指示、スキル、プラグイン、MCP（外の道具へつなぐ仕組み）、フック（特定の操作で動く処理）、権限、認証、会話履歴は、道具自身が通常どおり読みます。

宿りは作業場所の信頼や MCP の利用可否を代わりに承認しません。必要な確認は、その道具の通常の画面で行ってください。別途、通常起動を済ませてからやり直す必要はありません。

宿りを付けた起動では、話しかけるたびに名乗り、気持ち、直近の会話、関係する記憶が加わります。完成した一往復が宿りの記憶に残ります。普段の指示と宿りの名乗りが矛盾すると応対へ影響するため、両方の内容を確認してください。

## 起動と再開

```console
$ yadori claude
$ yadori claude --resume
$ yadori codex
$ yadori codex resume --last
$ yadori agy
$ yadori agy --continue
```

道具名の後ろの引数を、その道具へ渡します。`--prepare auto|ask|skip` は宿りの起動前処理の指定です。道具の履歴は通常の場所へ残り、終了時に捨てません。普段の設定ファイルへ宿りの処理を常時登録することもありません。

Claude Code には追加のフック設定と記憶の MCP だけを渡します。Codex には起動時の設定として同じ機能を追加します。Codex のフックが未確認なら、通常の `/hooks` で内容を確認して信頼してください。宿りは確認を省略する起動オプションを付けません。

agy には宿り用の追加ディレクトリを渡し、そこにフックと記憶の MCP を置きます。普段の設定・履歴の場所を差し替えず、起動中の会話を識別して宿りの回復用記録を分けます。

## 起動前の取り込み

起動時には取り込んだ件数と残る保留を短く表示します。未完・対象外の各ファイルの案内や、過去の会話本文は毎回並べません。破損など取り込みを妨げる失敗は表示します。詳細は [手動の取り込み](importing.md)で確認できます。

宿りの一時状態と、道具の会話履歴は別のものです。agy が記憶へ保存できなかった場合は回復用原文を残し、次回起動時に再試行します。回復記録を確かめる前に削除しないでください。

## ソースから使う

apt で導入済みなら不要です。ソースから使う場合は、リポジトリで `uv tool install --editable .` を実行します。Codex のデスクトップ画面や Gemini CLI は、この起動コマンドの対象外です。
