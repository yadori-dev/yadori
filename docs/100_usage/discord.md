# Discordで話す

[READMEへ戻る](../../README.md) · [使い方の一覧](README.md)

```console
$ cat ~/.yadori/discord.toml
token = "<Discord の bot のトークン>"
owner_id = 123456789012345678

$ yadori discord
（そら が Discord に居ます。終わるには Ctrl-C）
```

Discord から宿りへ話しかけられます。端末で話した続きが Discord でも続き、Discord で話した続きが端末でも続きます。覚えていることも、今の気持ちも性格も、同じ一人ぶんです。

繋ぐには、Discord の開発者向けの画面で bot を作り、次の二つを済ませてください。

1. アプリケーションを作り、Bot のトークン（その bot を見分けるための長い文字列）を取る
2. 作った bot を自分のところへ招き、直接の会話（DM）で話しかける

受け取るのは直接の会話だけなので、**MESSAGE CONTENT INTENT（届いた言葉の中身を読む許可）を入れる必要はありません。**

トークンと、自分のユーザーID（Discord の画面で自分の ID をコピーできます）を `~/.yadori/discord.toml` に書きます。**トークンはリポジトリへ入れないでください。**

応対を作れなかったときは、Discord には応対できないことだけが返り、理由は宿りを動かしている手元の画面に出ます。

答えるのは、その `owner_id` の人からの直接の会話だけです。サーバーの部屋の言葉はそもそも受け取らず、他の人の言葉、宿り自身の言葉には答えません（[ADR-019](../010_decisions/ADR-019-Discordへはbotとして繋ぎトークンを持ち主の手元に置く.md)）。動かし続けるのは持ち主の道具（`systemd` や `tmux` など、閉じたあともプログラムを動かし続ける仕組み）に任せます。
