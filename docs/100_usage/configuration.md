# 人物と設定

[READMEへ戻る](../../README.md) · [使い方の一覧](README.md)

`yadori setting` で名前・呼び名・持ち主・話し方、人物の切替、道具の優先順、起動前の準備を編集します。話し方は複数行で入力し、単独の `.` で確定します。未入力のまま `.` を入れると現在値を保持し、`/cancel` で取り消せます。保存確認で `y` を選ぶまで書き込みません。

道具の既定順はCodex → Claude Code → agyです。未導入・未対応の候補は飛ばしますが、選んだ後のログイン切れや失敗では別の道具へ再送しません。`yadori claude` などの明示指定は、その起動だけを上書きします。道具順の変更は次の起動・処理から反映し、起動中のDiscordは再起動が必要です。

保存先は `YADORI_HOME/settings.toml`（既定は `~/.yadori/settings.toml`）です。記憶の `memories.sqlite` は移動しません。旧 `dweller.toml` と `identity.md` は、新しい設定が無い間はそのまま読めます。初回の編集保存で入力済みの値を取り込み、旧ファイルも残します。**移行後に編集するのは `settings.toml`** です。旧版で引数なしの `yadori` を端末チャットとして使っていた場合は `yadori chat` に変更してください。

```toml
version = 1
active = "sora"
priority = ["codex", "claude", "agy"]

[people.sora]
id = "sora"
name = "そら"
nickname = "そら"
owner = "あなたの名前"
identity = "わたしはそらです。ていねいな言葉で話し、園芸を好みます。"
```

別の人物は同じ形の `[people.umi]` などの表を手で用意し、setting の人物切替から選べます。表のキーと `id` は一致させ、既存の人物の識別子を変えないでください。呼び名や名乗りを変えても識別子は保持するので同じ記憶を引き継ぎます。旧設定で `id` を省いていた場合は、移行前の呼び名を識別子として固定します。人物を切り替えて戻すと、その人物の記憶・状態から続けられます。

優先順は候補を省いても構いませんが、空の順序・重複・未知の名前は使えません。必要なら共通の `[models]` 表で `codex`、`claude`、`agy` ごとのモデル名を指定できます（内部の応対・要約・判定用）。旧人物設定の `model` は Claude 用として保持し、他の道具へ渡しません。Codex と agy は指定が無ければ道具の既定モデルを使い、対話起動のモデル設定は各道具の既存の約束を引き継ぎます。
