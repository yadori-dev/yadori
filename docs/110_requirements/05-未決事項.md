# 未決事項

ここには、要求の意味や受入判定を変える未確認だけを置く。解決した経緯はGitに残し、この一覧へ積み上げない。

| 未決事項 | 何が分かれば閉じられるか | 影響先 |
|---|---|---|
| 観測のほとんどが一人に由来する | 別の利用者が同じ困りごとを持つか確認する。特に「疎まれる頻度」は人によって大きく違う可能性がある | 全体 |
| 宿り自身を表す言葉が決まっていない | 記憶、気持ち、性格、気がかりをまとめて持つものを何と呼ぶか決める。決まるまで、その集合体へ名前を付けない | [`../150_system/用語集.md`](../150_system/用語集.md) |
| 気持ちが薄れる速さが決まっていない | 実際に会話しながら、次の会話まで残ってほしい長さを測る | `REQ-004` `AC-004` |
| 気持ちをいくつの軸で表すか決まっていない | 一つの強さだけで足りるか、複数の向きが要るかを、実際の会話で確かめる | `REQ-004` |
| 性格が変わってよい範囲が決まっていない | 変わってほしい部分と、変わってほしくない部分を利用者へ確認する。範囲を決めずに変動させると、成長ではなく劣化として受け取られる恐れがある。変わってほしくない部分は名乗りへ書く | `REQ-005` `AC-005` `REQ-013` |
| 名乗りと性格の境目を誰が決めるか固まっていない | 持ち主が毎回決めるのか、既定の分け方を用意するのかを決める | `REQ-013` |
| 話しかける頻度の上限が決まっていない | 一日に何回までなら疎まれないかを、実際に受け取って判断する | `REQ-008` `AC-008` |
| 思い出した記憶が気持ちを動かす度合いが決まっていない | 思い出しただけで動くのか、動くとしてどれだけかを決める。動かすと決めた場合、思い出すと覚えるの順序に依存が生まれる | `REQ-004` `REQ-006` |
| 話す前に確かめる範囲が決まっていない | 自分の記憶の中だけを確かめるか、外部も調べるかを決める。外部を調べる場合、費用と、誤った情報を持ち出す危険が増える | `REQ-008` `AC-008` |
| 生まれた時点で過去を持たせるかが決まっていない | 既に手元にある過去の対話の履歴を、最初の記憶として取り込むかを決める | `REQ-001` |
| 評価セットの作り方が決まっていない | 何件、どういう組み合わせで作れば、実際の会話での感覚と一致するかを試す | `REQ-011` `AC-006` `AC-011` |
| 外部へ会話が渡ることの説明の水準が決まっていない | 利用者が判断できる粒度を確認する | `REQ-012` `AC-012` |

未決のままでも増分を進められる場合は、どこまでを仮定したかをそのINC文書に一行で書く。受入判定そのものができない場合は進めない。
