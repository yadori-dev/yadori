# 受入基準

受入基準は、要求を満たしたかを利用の場面で判定する。実装方法ではなく、外から観測できる状態を書く。

| 基準 | 判定する状態 | 場面 |
|---|---|---|
| `AC-001` → `REQ-001` | 前のセッションで話した内容について、話す人が説明も検索の指示もしないまま、それを踏まえた応対が返る | `SC-001` `SC-002` |
| `AC-002` → `REQ-002` | 一度の応対について、思い出した記憶の一覧、それぞれの近さの値、渡した順序を後から読める。思い出さなかったことも、思い出す対象が無かったのか、閾値に届かなかったのかを見分けられる | `SC-009` |
| `AC-003` → `REQ-003` | 二つ以上の道具から続けて話しかけると、どちらでも直前のやりとりを踏まえ、同じ気持ちの状態を持つ。道具ごとの口調の差は、覚えている内容と状態の差として現れない | `SC-003` |
| `AC-004` → `REQ-004` | 一度の会話で気持ちが動き、その値が会話の終了後も残る。時間が経つと動く前の値へ向かって薄れ、薄れ方はAIモデルを呼ばずに同じ入力から同じ結果になる | `SC-004` |
| `AC-005` → `REQ-005` | 応対の傾向について、いつ、どの出来事によって、どちらへどれだけ動いたかを時系列で読める。任意の過去時点の値を求め直せる | `SC-012` |
| `AC-006` → `REQ-006` | 用意した評価セットの各件について、期待した記憶が定めた順位までに入り、出てはいけない記憶が閾値を越えない | `SC-002` `SC-010` |
| `AC-007` → `REQ-007` | 話しかけられていない時間に整理が行われ、何を読み直し何に気づいたかが一回分の記録として残る。整理の前後で会話の原文が一件も減らない | `SC-005` |
| `AC-008` → `REQ-008` | 宿りから届く各回に理由が記録される。一日の上限を越えて届かない。返事が無いうちは次が届かない。話す前の確認で解決済みと分かった件は届かず、その件が消えたことを読める | `SC-006` `SC-007` `SC-008` |
| `AC-009` → `REQ-009` | インデックスを全部消しても、保存された原文から作り直して同じ結果を得られる。作り直しの前後で会話の原文が一件も減らない。各インデックスがどの埋め込みのどの版で作られたかを読める | `SC-011` |
| `AC-010` → `REQ-010` | 複数の宿りを同じ常駐で動かしたとき、一方の発話に対して他方の記憶が思い出されない。記憶、状態、気がかり、夢のすべてが、いずれか一つの宿りに属する | `SC-013` `SC-016` |
| `AC-015` → `REQ-015` | 同じ持ち主の下に宿りを二つ作り、名前で相手を選べる。片方への発話でもう片方の記憶が思い出されず、気持ちも別々に動く。名乗りも宿りごとに別である | `SC-016` |
| `AC-011` → `REQ-011` | 思い出す条件を変えた前後で評価セットを測り、件ごとに良くなった点と悪くなった点を並べて読める | `SC-010` |
| `AC-018` → `REQ-018` | 手元の対話の記録のディレクトリを指すと、評価セットの形の下書きが手元に出る。下書きには覚えさせる発話と、後の発話が前の発話の話題を指す組の候補が並び、短い相槌や道具の命令は含まれない。人が確かめていない組はそのままでは測れず、確かめた下書きは測って件ごとの結果が出る。会話の原文はリポジトリの配下へ書かれない | `SC-019` |
| `AC-013` → `REQ-013` | 書いた名乗りのとおりの名前と話し方で応対が返る。会話を重ねて記憶が増えても、気分が変わっても、名乗りに書いた部分は変わらない。名乗りは項目ではなく一続きの文章として書ける | `SC-014` |
| `AC-014` → `REQ-014` | 名乗りを書き直した後も以前の版を読める。一度の応対について、どの版の名乗りで作られたかを読める。書き直しても過去の応対の記録が変わらない | `SC-015` |
| `AC-017` → `REQ-017` | 評価セットのうち、期待するやりとりと語が重ならない件で、期待した記憶が定めた順位までに入る。無関係な記憶が混ざる件は増えない。実際の会話から作った評価セットでも、語が重ならない件で同じことが確かめられる | `SC-018` |
| `AC-016` → `REQ-016` | 同じ近さの記憶が二件あるとき、思い出された回数の多い側が先に出る。長く思い出していない記憶は後ろへ下がるが、その話題を名指しすれば出てくる。一度の応対について、各記憶の近さと思い出しやすさを別々に読める | `SC-017` |
| `AC-012` → `REQ-012` | 使い始める前に、記憶の保存先と、会話が渡る外部の相手を読める。保存先はリポジトリの外にあり、消さずに移せる | `SC-013` |

`AC-013` と `AC-014` の名乗りについては [ADR-013](../010_decisions/ADR-013-名乗りは積まず書いたものを版で持つ.md) を参照する。

`AC-006` と `AC-011` の判定に使う評価セットは架空の会話で作る（[ADR-010](../010_decisions/ADR-010-思い出す質を評価セットで判定する.md)）。
