# 長く変わらない利用者の背景と課題

ここには、個別の増分より長く残る「誰が、どんな状況で、何に困り、何が満たされれば解決か」を置く。

- [`01-背景と課題.md`](01-背景と課題.md): 現在の手段では解決できていないこと
- [`02-利用者とシナリオ.md`](02-利用者とシナリオ.md): 人物の背景と、実際の使い方の流れ
- [`03-要求.md`](03-要求.md): 何が満たされれば解決と言えるか
- [`04-受入基準.md`](04-受入基準.md): どうなれば満たしたと判断できるか
- [`05-未決事項.md`](05-未決事項.md): まだ答えが無い問い

進行中の変更で期待する体験は、その Issue に書く。Issue を説明するために必要な背景だけをここから参照し、本文を写さない。

聞き取りで長く残る理解が変わった場合だけ、該当する記述を直す。現在の件数や、いつ何を追加したか、どの増分で使ったかは書かない。履歴は Git が持つ。

`PB`、`SC`、`REQ`、`AC` は、背景から受入判定までの対応を検索するために使う。番号だけで意味を伝えず、必ず短い名前を添える。

**利用者の実際の会話を、この配下のどの文書にも書かない。** 例が要る場面では架空の会話に置き換える。
