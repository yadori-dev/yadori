# 要求

要求は、解決に必要な状態を表す。実現方法は書かない。右端は、その要求が生まれた課題である。

| 要求 | 必要な状態 | 課題 |
|---|---|---|
| `REQ-001` | 前の会話の内容を、こちらが指示しなくても踏まえた応対を受けられる | `PB-001` `PB-002` |
| `REQ-002` | 一度の応対について、何を思い出し、それぞれをどれだけ近いと判定したかを後から読める | `PB-005` `PB-014` |
| `REQ-003` | 使う道具が変わっても、覚えていることと今の気分が同じ相手として続く | `PB-003` `PB-004` |
| `REQ-004` | 気持ちが会話によって動き、時間とともに薄れながら次の会話まで続く | `PB-004` |
| `REQ-005` | 応対の傾向が長い時間をかけて変わり、いつ何があってそう変わったかをたどれる | `PB-004` `PB-012` |
| `REQ-006` | 記憶が増えても、その会話に関係のないものが混ざらない | `PB-009` |
| `REQ-017` | 同じことを違う言い方で言っても、関係する記憶が出る。語が重なっていることを頼りにしない | `PB-021` `PB-024` `PB-002` |
| `REQ-016` | よく話題に出ることほど詳しく思い出され、めったに出ないことは奥へ沈む。沈んだものも名指しすれば出てくる | `PB-020` `PB-009` |
| `REQ-007` | 話しかけられていない間にも、記憶の整理と、そこでの気づきが起きる | `PB-006` `PB-010` |
| `REQ-008` | 宿りの側から話しかけられるが、各回に理由があり、頻度が抑えられ、既に解決した話は届かない | `PB-006` `PB-007` `PB-008` |
| `REQ-009` | 会話の原文が失われず、意味検索のAIモデルを入れ替えても記憶を作り直せる | `PB-011` |
| `REQ-010` | 一つの常駐で複数の宿りを、持ち主が同じ場合も違う場合も、記憶を混ぜずに扱える | `PB-013` |
| `REQ-011` | 思い出す条件を変えたとき、何が良くなり何が悪くなったかを測った値で比べられる | `PB-014` |
| `REQ-018` | 実際の会話の記録から、発話と出るべき記憶の組を評価セットとして作れる。人が期待を確かめる工程は残り、会話の原文は手元に留まる | `PB-022` `PB-014` |
| `REQ-019` | 既にある評価セットの下書きに、増えた記録の分だけを足せる。確かめた問は消えず、既に確かめた分の費用を二度払わない | `PB-023` |
| `REQ-012` | 会話がどこに保存され、外部のどの相手へ渡るかを、使い始める前に読める | `PB-015` |
| `REQ-013` | 宿りが誰であるか（名前、自分の呼び方、話し方、自分について変わってほしくない事柄）を持ち主が書け、それが応対に一貫して現れる | `PB-016` `PB-018` |
| `REQ-014` | 書いた名乗りを書き直したとき、以前の版と比べられ、過去の応対がどの名乗りで作られたかが分かる | `PB-017` |
| `REQ-015` | 一人の持ち主が、名前で見分けられる宿りを複数持て、記憶も気持ちも宿りごとに分かれる | `PB-019` `PB-013` |

`REQ-004` の薄れる速さ、`REQ-008` の頻度の上限など、値が未確定のものは [`05-未決事項.md`](05-未決事項.md) に残す。
