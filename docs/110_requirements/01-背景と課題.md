# 背景と課題

## 背景

主な利用者は、対話するAIを毎日長時間使って仕事をする開発者である。作業の相談、設計の判断、実装、振り返りの多くが、その対話の中で行われる。対話は端末やアプリのセッションとして区切られ、区切りをまたぐと相手は前回を覚えていない。

現在も、繰り返し使う指示や前提を設定ファイルへ書いておく手段はある。しかしそれは「毎回同じことを言う」を減らすもので、過去に何があったかを相手が持つことにはならない。

利用者は複数の対話する道具を使い分けている。道具ごとに設定を書いても、相手は道具ごとに別々である。

以下では、直接確認したことを「観測」、本人の評価を「本人の見立て」、資料や理屈から導いたことを「推定」と書く。

## 覚えない、思い出さない

| 課題 | 起きていること |
|---|---|
| `PB-001` 前回を覚えていない | セッションが変わると相手は初対面に戻る。同じ前提と経緯を毎回説明し直している。［観測］ |
| `PB-002` 覚えていても思い出さない | 記録を外に置いても、相手が自分から探しに行かなければ使われない。探す道具を渡しても、必要な場面で呼ばれるとは限らない。［観測］ |
| `PB-003` 道具ごとに別人になる | 同じ設定を複数の道具へ渡しても、記憶と状態が別々のため、続きの相手として扱えない。［観測］ |
| `PB-004` 関係が積み上がらない | 長く使っても相手の側に蓄積がなく、いつまでも初対面の応対が返る。［本人の見立て］ |
| `PB-005` 何を根拠に答えたか分からない | 見当違いの返事が来ても、何を踏まえてそう答えたのかを追えず、直しようがない。［観測］ |

## 誰でもない相手になる

| 課題 | 起きていること |
|---|---|
| `PB-016` 誰なのかが決まっていない | AIモデルそのままの応対には、名前も、決まった話し方も、自分についての事柄も無い。何度話しても、特定の相手と話している感覚にならない。［観測］ |
| `PB-017` 書き直した影響が分からない | 話し方や自分についての記述を変えると応対の全体が変わるが、変える前と比べる手段がないため、良くなったのか悪くなったのかを判断できない。［推定］ |
| `PB-019` 一つの人物ですべての用途に向かない | 相手に性格と得意分野を与えると応対が明確に変わる。用途が違えば向く相手も違うため、一人にすべてを持たせると応対が中途半端になる。別の道具での運用では、用途ごとに相手を分けて同時に動かしている。［観測］ |
| `PB-018` 変わってよい部分と変わってほしくない部分が混ざる | 応対の傾向が時間とともに変わることは望ましいが、名前や根本の話し方まで変わると、同じ相手として扱えなくなる。両者を分けて置く場所がない。［本人の見立て］ |

## 待っているだけで、何も起きない

| 課題 | 起きていること |
|---|---|
| `PB-006` 話しかけないと何も起きない | 相手は呼ばれたときだけ現れる。気づいたことを自分から持ってくることがない。［観測］ |
| `PB-007` 定刻の通知は疎まれる | 決まった時刻に届く挨拶や要約は、内容にかかわらず通知として扱われ、読まれなくなる。［本人の見立て］ |
| `PB-008` 終わった話を持ち出される | 事前に決めた内容をそのまま届ける仕組みは、届く時点で解決済みかどうかを見ない。［推定。既存の通知系の道具からの類推］ |

## 貯めるほど濁る

| 課題 | 起きていること |
|---|---|
| `PB-009` 増えるほど無関係が混ざる | 記録が増えると、意味の近さで探しても関係の薄いものが上位へ来る。会話に無関係な話題が混ざる。［推定。件数を増やした場合の一般的な挙動］ |
| `PB-020` 一度きりの話と毎週の話が同じ重みで並ぶ | 何度も話題に出ることと、二年前に一度だけ出て以来触れていないことが、同じ扱いで思い出される。人が相手ならよく話すことほど詳しく覚えているが、その差が無い。［本人の見立て］ |
| `PB-021` 同じことを違う言い方で言うと思い出せない | 語が重なる発話では思い出せるが、同じ話題を別の言葉で言うと出てこない。評価セットで測ったところ、語の重なりが無い件は、思い出す条件をどう動かしても引けなかった。緩めると先に無関係な記憶が混ざる。［測定］ |
| `PB-010` 整理する機会がない | 会話のたびに増えるが、まとめ直す時機がない。増え続ける前提の保存先になっている。［観測］ |

## 長く使うと壊れる

| 課題 | 起きていること |
|---|---|
| `PB-011` 道具の都合で記憶が失われる | 意味検索に使うAIモデルを入れ替えると、それまでのインデックスが使えなくなる。作り直せない形で持っていると、記憶そのものが失われる。［推定。AIモデルの更新頻度からの見通し］ |
| `PB-012` 育った結果を戻せない | 相手の応対が長い時間をかけて変わったとき、いつ何があってそうなったかが残らないと、望まない方向へ寄っても戻せない。［推定］ |
| `PB-013` 記憶が混ざる | 一つの仕組みで複数の人の記憶を扱うとき、持ち主を持たない形で貯めると、混ざったことに気づいた時点で分離できない。［推定］ |

## 中身が見えない

| 課題 | 起きていること |
|---|---|
| `PB-014` 良くなったか悪くなったか分からない | 思い出す条件を変えても、何が良くなり何が悪くなったかを比べる手段がなく、感覚で調整することになる。［本人の見立て］ |
| `PB-022` 実際の会話で測る評価セットを手で書くしかない | 思い出す質は実際の会話から作った評価セットで測ると決めたが、手元にある対話の記録から、発話と出るべき記憶の組を人が読んで一件ずつ書き写しており、数十件が限度である。［観測］件が少ないと条件を替えた効果が数件の当たり外れで揺れ、選んだ本人の都合も入る。［推定］ |
| `PB-015` 会話がそのまま外へ出る | 対話の内容は私生活、仕事、人間関係を含む。保存先と、外部のどの相手へ渡るかが利用者に見えていないと、扱いを判断できない。［観測］ |

課題どうしには因果があるが、同じものではない。たとえば「覚えている」と「思い出す」、「自分から話しかける」と「疎まれない」は別々に満たす。
