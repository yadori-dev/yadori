# INC-068 Claude Code を宿りとして起こし、作業に付き添わせる

| 項目 | 内容 |
|---|---|
| Issue | #68 Claude Code を宿りとして起こし、作業に付き添わせる |
| 選んだ受入基準 | `AC-001` 指示しなくても前の会話を踏まえる、`AC-003` 道具を変えても同じ相手として続く |

## 体験の変化

作業に付き添わせる人が一度 yadori を手元の道具として入れ、作業するディレクトリで `yadori claude` と打つと、普段の Claude Code の定額契約と作業道具を使い、宿りの名乗りで応対する Claude Code が立ち上がる。話しかけるたび、関係する記憶、直近のやりとり、今の気持ちと性格、最近の夢が返事を作る前に渡る。返事が終わるたび、その発話と最後の返事だけがすぐ宿りの記憶へ一件残り、返事の末尾の印から気持ちが動く。

Claude Code が普段読む `CLAUDE.md`、`CLAUDE.local.md`、rules（条件に応じて読む指示）、自動記憶は、この起動では読ませない。認証、権限、スキル、プラグイン、MCP（外の道具へ接続する仕組み）は、安全と人格に関わる項目を除き、起動時点の普段のものを使う。発話と返事の対応を保てない背景作業と会話中の予約は使わない。借りる項目の境界は [ADR-020](../010_decisions/ADR-020-Claude-Codeの会話履歴を宿り専用に分け手元の設定は参照して使う.md) で固定する。

作業中は Claude Code が同じ会話の手順と結果を持つが、その履歴は終了時に捨て、過去の会話を再開できない。長く残るのは宿りの一往復だけとする（[ADR-016](../010_decisions/ADR-016-応対は対話する道具を通して作り、その道具の文脈を持ち込まない.md)）。常駐と受付は増やさず、Claude Code の正式なフックから既存の `Conversation.recall` と `Conversation.remember` を別々の時点で呼ぶ（[ADR-012](../010_decisions/ADR-012-会話の入口を思い出すと覚えるの二つに分ける.md)）。

## 入口の例

```console
$ uv tool install --editable .
（yadori のリポジトリで一度だけ実行する）

$ cd <付き添わせたい作業場所>
$ yadori claude
（そら として Claude Code を起こします）
```

立ち上がった Claude Code で「前にこの保存の形を変えないと決めた理由は？」と尋ねると、宿りの名乗りで、関係する記憶を踏まえて答える。従量課金の鍵が優先される状態や Claude Code が見つからない状態では、理由と直し方を示して起動しない。

## 手段の候補

| 候補 | 判断 |
|---|---|
| `IDEA-068-001` 普段の Claude Code の設定へ宿りのフックを足す | どの起動を覚えるか選べず、普段の作業や宿りが裏で呼ぶ Claude Code まで記憶するため採らない |
| `IDEA-068-002` Claude Code の安全起動を使う | 手元の指示と一緒にフック、スキル、プラグイン、MCP も止まり、作業へ付き添えないため採らない |
| `IDEA-068-003` 起動ごとの専用設定から起こし、普段の設定は許した項目だけ借りる | **採る。** 宿りのフックと会話履歴をその起動へ閉じたまま、作業道具の現在値へ追従できる |

## 要件とシステムテスト

| 要件と根拠 | 必要な振る舞い |
|---|---|
| `SPEC-068-001`（`AC-001` `AC-003`）Claude Code を宿りとして起こす | 任意の作業場所で `yadori claude` を実行すると、宿りの名前と話し方の Claude Code が立ち上がる。定額契約だけを使い、普段の作業道具は ADR-020 の境界で借りる。作業場所に設定や道具があり普段の Claude Code で未信頼なら、先に内容を確認する手順を示して起動しない。危険モード、Claude.ai の接続先、背景作業と会話中の予約は停止する。指示と自動記憶は除外する。会話履歴は普段の履歴と混ぜず、終了後に捨てる |
| `SPEC-068-002`（`AC-001` `AC-003`）返事の前に思い出す | 発話ごとに関係する記憶、直近のやりとり、今の気持ちと性格、最近の夢を渡す。フックの応答全体を JSON にした UTF-8 の長さは九千バイト以内とし、名乗りと状態、直近の最新一往復、関連が強い記憶、残る直近の往復、夢の順で残す。入らない原文は文字の境界で切り、省いたことを明記する。名乗りと状態だけで上限を超えるなら発話を処理させない |
| `SPEC-068-003`（`AC-003`）最後の返事を一度だけ覚える | 通常の `Stop` で同じ `prompt_id` の発話と最後の返事を一往復としてすぐ覚える。思い出した時刻と `prompt_id` の出典を残し、再送では一件しか増やさない。気持ちの印は返事の本文から外す。別の Stop フックが返事を続けさせる使い方は、この起動へ常時動くフックを借りないため扱わない |
| `SPEC-068-004`（`AC-001` `AC-003`）準備不足とフックの失敗を隠さない | 起動の準備が整わなければ起動しない。前の往復を覚えられない、または現在の発話で思い出せなければ、終了状態 2 で現在の発話を止める。終了時に覚えられなければ理由を画面へ返す。`StopFailure` の発話はその時点で捨てる。利用者が割り込んで `Stop` が来なかった発話は、同じセッションの次の `UserPromptSubmit` または `SessionEnd` で捨てる。未完の発話は二十四時間を超えて残さない。フック自身が時間切れすると発話を止められない制約は受け入れる |

## 今回扱わないこと

Codex と Gemini への付き添い、宿りの側から話しかけること、持ち主の指示を人格と作業規則に分けること、プラグイン自身が提供する MCP、背景作業と会話中の予約、別の Stop フックが返事を続けさせる使い方、長い記憶を要約すること、会話の圧縮そのものを宿りが制御することは扱わない。

管理された指示は利用者が除外できないため、名乗りと衝突する組織の管理下では同じ話し方を保証しない。Claude Code がフックを時間切れにすると、思い出しが無いまま発話を処理する現在の制約も受け入れ、通常の応答時間に十分な上限を置く。
