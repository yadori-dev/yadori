## 体験の変化

話す人は、前に使った語を思い出さなくてよい。「ベランダにトマトの苗を植えました」と話した後、「植物の世話について教えてください」と尋ねても、宿りはその件を踏まえて答える。覚えているのは話題であって語ではない、という前提で話せる。

持ち主の定額契約で動かす前提は変わらない。模型の提供元への鍵を必要とせず、手元で完結する。

替えた効果は `INC-018` の仕組みで測る。架空の評価セットと、実際の会話から作った評価セットの両方で確かめる。架空の会話だけでは、語を選んだ本人が都合よく当ててしまう（[ADR-010](../010_decisions/ADR-010-思い出す質を評価セットで判定する.md)）。

よく話すことほど詳しく思い出すこと（`AC-016`）、一度の会話の思い出しを読む入口（`AC-002`）は別の増分が持つ。実際の会話から評価セットを作る道具は作らない。手で書ける範囲で足りることを `INC-018` の確認で確かめた。

## 入口の例

```console
> ベランダにトマトの苗を植えました
そら: いいですね。日当たりに気をつけてください。
（別の話題をいくつか挟む）
> 植物の世話について教えてください
そら: トマトの苗を植えられたと伺いました。水やりは……

$ uv run python -m yadori measure
5件中 5件で期待したやりとりが上位3件に入った
出てはいけないやりとりが出た件: 0件
```

## 手段の候補

- `IDEA-025-001`: 思い出す条件をさらに調整する。`INC-018` で測ったとおり、語が重ならない件は下限をどう動かしても引けず、緩めると先に無関係な記憶が混ざる。届かないため採らない
- `IDEA-025-002`: 模型の提供元の埋め込みへ鍵で繋ぐ。質は見込めるが、定額契約で動かす前提（[ADR-016](../010_decisions/ADR-016-応対は対話する道具を通して作り、その道具の文脈を持ち込まない.md)）を崩し、会話のたびに課金が積み上がるため採らない
- `IDEA-025-003`: 手元で動く意味の埋め込みへ替える。鍵が要らず、外へも繋がらない。導入する物の大きさと応答の速さが代償になる。採る
- `IDEA-025-004`: 手元で動く候補が複数あるため、`INC-018` の仕組みで同じ評価セットに当てて比べ、測った値で選ぶ。どれを採るかは実装のときに決める

## 要件とシステムテスト

| 要件と根拠 | 必要な振る舞い |
|---|---|
| `SPEC-025-001`（`AC-017`）語が重ならなくても思い出す | 話しかけられた文章と語が重ならないやりとりでも、話題が同じなら探した記憶に現れる。無関係なやりとりが混ざる件は、替える前より増えない。架空の評価セットと、実際の会話から作った評価セットの両方で成り立つ |
| `SPEC-025-002`（`AC-017`）替えても原文は失われず、作り直せる | 埋め込みを替えると、それまでの索引は使えなくなる。原文は一件も失われず、索引を作り直せば、替える前から保存されている記憶も新しい埋め込みで探せる。どの埋め込みで作った索引かを、索引ごとに読める |
| `SPEC-025-003`（`AC-017`）鍵を要求せず手元で完結する | 模型の提供元への鍵が無く、外へ繋がらない状態でも思い出せる。導入したものが手元に無い場合は、思い出す前に理由を返す。何を導入すればよいかが理由から分かる |
