# INC-070 Codex を宿りとして起こし、作業に付き添わせる

| 項目 | 内容 |
|---|---|
| Issue | #70 Codex を宿りとして起こし、作業に付き添わせる |

## 体験の変化

作業に付き添わせる人が作業場所で `yadori codex` と打つと、普段の Codex の ChatGPT 契約と作業道具を使い、宿りの名乗りで応対する Codex が立ち上がる。話しかけるたび、関係する記憶、直近のやりとり、今の気持ちと性格、最近の夢が返事を作る前に渡る。返事が終わるたび、その発話と最後の返事だけがすぐ宿りの記憶へ一件残り、返事の末尾の印から気持ちが動く。

Codex が普段読む `AGENTS.md`、`AGENTS.override.md`、追加の開発者向け指示、人格、自動記憶は、この起動では読ませない。認証、AIモデル、考える深さ、承認方針、画面表示、信頼済みディレクトリ・規則・MCPは、安全と人格に関わる項目を除き普段のものを使う。常時フック、遠隔操作、危険な確認省略は使わない。借りる項目の境界を固定し、差分を起動とフックの変換へ閉じ、思い出し・文脈上限・未完管理・保存と再送の規則は複製しない。

作業中は Codex が会話の手順と結果を持つが、その履歴は終了時に捨て、過去の会話を再開できない。長く残るのは宿りの一往復だけとする（[ADR-016](../010_decisions/ADR-016-応対は対話する道具を通して作り、その道具の文脈を持ち込まない.md)）。常駐と受付は増やさず、Codex の正式なライフサイクルフックから既存の会話の口を呼ぶ。

## 入口の例

```console
$ cd <付き添わせたい作業場所>
$ yadori codex
（そら として Codex を起こします）
```

立ち上がった Codex で「前にこの保存の形を変えないと決めた理由は？」と尋ねると、宿りの名乗りで、関係する記憶を踏まえて答える。ChatGPT 契約でない認証、API キーによる従量課金、未信頼の作業場所、Codex が見つからない状態では、理由と直し方を示して起動しない。

## 手段の候補

| 候補 | 判断 |
|---|---|
| `IDEA-070-001` 普段の Codex の設定へ宿りのフックを足す | どの起動を覚えるか選べず、普段の作業や宿りが裏で呼ぶ対話道具まで記憶するため採らない |
| `IDEA-070-002` Codex の一時セッション引数を使う | 設定や履歴の隔離が保証されず、フックと名乗りを作業場所に閉じられないため採らない |
| `IDEA-070-003` 起動ごとの専用設定から起こし、普段の設定は許した項目だけ借りる | **採る。** 宿りのフックと会話履歴をその起動へ閉じたまま、ChatGPT 契約と作業道具の現在値へ追従できる |

## 要件とシステムテスト

| 要件と根拠 | 必要な振る舞い |
|---|---|
| `SPEC-070-001`（`AC-001` `AC-003`）Codex を宿りとして起こす | 任意の信頼済み作業場所で `yadori codex` を実行すると、宿りの名前と話し方の Codex が立ち上がる。ChatGPT 契約だけを使い、普段の作業道具は許可した境界で借りる。未信頼なら確認手順を示して起動しない。指示ファイル、常時フック、危険モード、API キーは停止・除外する。会話履歴は終了後に捨てる |
| `SPEC-070-002`（`AC-001` `AC-003`）返事の前に思い出し、圧縮後も名乗りを戻す | 発話ごとに関係する記憶、直近のやりとり、今の気持ちと性格、最近の夢を渡す。応答全体の JSON は UTF-8 で九千バイト以内とし、一時ファイルへ退避させない。会話圧縮後（compact）も名乗りと状態を戻す。名乗りと状態だけで上限を超えるなら発話を処理させない |
| `SPEC-070-003`（`AC-003`）主たる担当の最後の返事を一度だけ覚える | 主たる担当の正常な `Stop` で同じ `turn_id` の発話と最後の返事を一往復としてすぐ覚える。思い出した時刻と出典を残し、再送では一件しか増やさない。気持ちの印は返事本文から外す。下位の担当（SubagentStop）は個別の一往復として保存しない |
| `SPEC-070-004`（`AC-001` `AC-003`）準備不足、中断、フックの失敗を隠さない | 起動の準備が整わなければ起動しない。中断（Interrupt）された発話や失敗した往復は記憶しない。保存失敗は画面へ警告し未確定の往復を残して再試行する。未完の発話は二十四時間を超えて残さない |

## 設計と結合テスト

| 設計判断 | 実現する要件 | 構造と責務 |
|---|---|---|
| `AD-070-001` Codex の起動と借りる設定を adapter/tool へ閉じる | `SPEC-070-001` `SPEC-070-004` | `adapter/tool` が起動ごとの専用設定を作り、許可項目だけを普段と作業場所の現在値から写す。worktree では git-common-dir から求めた元チェックアウトで信頼と手元設定を照合し、規則は worktree から読む。危険モード、API キー、AGENTS.md、常時フックを除外する。`additionalContextLimit = 0` と宿りのフックを config へ設定する。ChatGPT 認証を確かめ、同じ端末につないで待つ |
| `AD-070-002` フックの入出力と未完の発話を adapter/tool へ閉じる | `SPEC-070-002` `SPEC-070-003` `SPEC-070-004` | 正式な `turn_id` と `session_id` を読み、発話、思い出した時刻、名乗りの版を専用ディレクトリに施錠して持つ。主担当の `Stop` で確定し、Interrupt で未完を捨てる。SessionStart の compact で名乗りを戻し、SubagentStop は無視する。二十四時間を超え施錠の無い古い置き場を次回起動で消す |
| `AD-070-003` 会話の口が起動準備、時刻、名乗りの版、再送の整合を持つ | `SPEC-070-002` `SPEC-070-003` | 既存の会話の口（Conversation）を共用する。出典（session_id と turn_id）を一意にし、再送時は原文と気持ちの整合を確かめる。原文と気持ちは同一取引で確定し、索引失敗時は補完する。保存失敗時は未完を残して画面へ警告し、再送で確定できる |
| `AD-070-004` 名乗りと思い出しを Codex が読む長さに組む | `SPEC-070-001` `SPEC-070-002` | Claude Code と共通の文脈組み立て部品を使う。名乗りと状態、最新直近、関連記憶、残る直近、夢の順で組み、応答全体の JSON を九千バイトへ収める。返事の印を本文と動きへ分ける部品も共用する |

## 今回扱わないこと

Codex のデスクトップ画面、IDE 拡張、クラウド作業、遠隔操作、過去の Codex セッションの再開、宿りの側から話しかけること、持ち主の指示を人格と作業規則へ自動で分けること、長い記憶の要約、管理された設定との衝突解消は扱わない。
