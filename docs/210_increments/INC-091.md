# 普段の対話する道具の会話を宿りへ取り込む

対応: [Issue #91](https://github.com/yadori-dev/yadori/issues/91)。受入基準: `AC-001`、`AC-002`、`AC-003`、`AC-010`。

## 要件

|要件|入力と結果|テスト|
|---|---|---|
|`SPEC-091-001` 選んだログを確認して取り込む|`yadori import claude/codex/agy --from PATH --person ID` は対象の宿り、元ファイル、追加予定・既存・未完・除外理由を表示する。`--apply`を付けた場合だけ完成した往復を保存する。ディレクトリは対応する原文を再帰的に読む。対象なし・読めない入力・未対応形式は非ゼロで理由を出す|`ST-091-001`|
|`SPEC-091-002` 元の発話と完成応対を対応させる|通常CLIの原文にある人物の発話、完成した応対、元時刻、道具、セッションと発話識別子を保つ。途中の報告、思考、ツール結果、子担当、システム指示、画像だけの発話を往復にしない。中断・分岐・別会話を誤って連結しない|`ST-091-002`|
|`SPEC-091-003` 繰返し・追記・競合|同じ出典と同じ本文は追加しない。既存に後から完成した往復だけ足せる。同じ出典で本文や対応が変われば上書きせず競合として失敗する。読み取り段階の破損・競合は全件を書かず停止する。保存は原文と索引を一往復ずつ確定し、途中失敗では確定済み件数と残りを表示する。再実行で確定分を重複させない。ファイル移動や複製でも元識別子で判定する|`ST-091-003`|
|`SPEC-091-004` 記憶の所有と出典|指定人物を開始時に固定し、起動中のactive人物の変更に追従しない。自動提示・追加検索・原文取得のどの入口でも、外部のどの道具との会話かを本文より先に示す。他人物の外部会話を返さない|`ST-091-004`|
|`SPEC-091-005` 人物の状態と原文を維持|確認だけではDBを作成・変更しない。取り込みは名乗り・気持ち・性格・思い出した回数を作らない。元ログを書き換えない。通常の夢・短文補完は外部会話を対象にしない|`ST-091-005`|
|`SPEC-091-006` 原文を検索して続きへ使う|取り込み後の外部会話は同じ埋め込みで索引化して自動提示・MCP検索から利用できる。候補全体の件数と本文量は既存上限を超えない。MCPは出典を示して選んだ本文を既存の頁上限内で取得する|`ST-091-006`|
|`SPEC-091-007` 形式の限界を見せる|末尾の書きかけ行・未完応対は件数と理由を出し次回へ残す。途中の壊れた行を飛ばして成功扱いしない。agyはtranscript_full.jsonlを使い、要約・履歴・DBのBLOBから原文を推測しない。yadori自身の出典と重なる通常往復は再取り込みしない|`ST-091-007`|

## 起動時の準備

|要件|入力と結果|テスト|
|---|---|---|
|`SPEC-091-008` 起動時に取り込みと夢を行う|初回に取り込み元と「自動・毎回確認・実行しない」を人物ごとに保存する。通常のyadori/claude/codex/agy/chat起動で、固定した人物へ取り込み→夢の順に各一回処理し会話を始める。道具のフック・MCP・夢内部の呼出しでは準備しない|`ST-091-008`|
|`SPEC-091-009` 選ぶ・飛ばす・取り消す|毎回確認では取り込みと夢を個別に選べる。`--prepare ask/auto/skip`で今回だけ変えられる。質問できない入力では未設定・確認モードは待たず案内して会話へ進む。自動設定済みの場合だけ処理する。Ctrl+Cは実行中の子も止め、確定済みを保ち会話へ進む|`ST-091-009`|
|`SPEC-091-010` 量と残件を示す|起動時の取り込みは新規200往復まで、夢は既存の一回の上限までとし残件を示す。取り込み0件でも自身の未処理会話・前回失敗・補完残件があれば夢を実行する。取り込みは外部会話を検索可能にし、夢は自身の会話を整理する|`ST-091-010`|
|`SPEC-091-011` 並行起動と失敗|同じ人物の準備は同時実行せず、他の準備が動いていれば案内して会話へ進む。ログの失敗は保存済み分と理由を示し、正常な保存先では夢・会話へ進む。人物または記憶保存先を安全に確定できない場合は起動しない|`ST-091-011`|

|テスト|対応|入力と期待する結果|
|---|---|---|
|`ST-091-008`|`SPEC-091-008`|初回で元ログと動作を選び保存し、2回目の通常起動で増分取り込み→夢→会話の順。3つの道具で同じ準備を使い、内部呼出しでは再帰しない|
|`ST-091-009`|`SPEC-091-009`|今回だけskip、毎回確認の個別選択、EOF、非TTY、実行中Ctrl+Cを通す。設定済み自動だけ非対話で処理し、子を残さず確定分を維持する|
|`ST-091-010`|`SPEC-091-010`|新規201件、自身の夢残件、取り込み0件、未処理なしを与え、1バッチの上限と残りが表示される。外部本文を自身の夢へ混ぜない|
|`ST-091-011`|`SPEC-091-011`|並行2起動、読み取り不能ログ、夢の失敗、人物不明・保存先破損を通し、既定の停止/続行と理由を確認する|

## 設計

|設計|責務と境界|テスト|
|---|---|---|
|`AD-091-001` 原文の読み手|三形式を別の読み手で解析し、外部会話（道具・会話・発話・応対識別子・原時刻・本文・直接の前後）へ揃える。ファイルは読取開始時のサイズまで固定して読み、末尾だけの不完全JSONを未完として区別する。ClaudeはparentUuidを辿った利用者にend_turnの応対を結び、Codexはturn_idとfinal_answer/task_completeで完了を確認し、agyはUSER_EXPLICITとその後の道具呼出しのないMODEL/DONEを対応させる。複数の未確定利用者や根拠のない前後関係は結ばず理由を残す|`IT-091-001`|
|`AD-091-002` 外部会話の保存|同じSQLiteに外部会話と索引の別表を追加する。自身のepisode・名乗り版・状態・夢の表には書かない。人物・道具・元セッション・元発話を一意にし、本文・応対識別子・時刻・確定した直接先行の一致を照合する。後続は保存済みの先行関係から求め、追記で元の記録を変えない。全入力の解析・重複・競合を確認してから保存し、各往復の原文と索引を同一取引で確定する。確認は読取専用接続、DB不在なら空として読み変更しない|`IT-091-002`|
|`AD-091-003` 自動提示とMCP|外部会話の検索口を共有し、同じ埋め込みの通常候補と外部候補を近さ順で合計件数まで選ぶ。Recollectionに外部候補を分けて持ち、全表示口で外部道具名と出典を本文より先に出す。一時参照は記録種別と番号の組で一意にし、取得時も固定人物を確認する。外部原文は記録済みの直接前後だけを既存の頁・予算上限で返す|`IT-091-003`|
|`AD-091-004` 起動前の準備|人物ごとに準備の動作と取り込み元を設定する。通常のEntryだけで選択→設定スナップショット→人物別非待機ロック→取り込み一バッチ→夢一バッチ→対話を組み立てる。夢は固定設定を渡せる既存の処理を共用し、取り込み件数で抑止しない。開始前の個別選択とKeyboardInterruptの子停止・部分確定保持を分ける。入力不能・ログ失敗・準備中の他起動は案内して進み、固定人物/DB不正は止める|`IT-091-004`|

|テスト|対応|入力と期待する結果|
|---|---|---|
|`IT-091-001`|`AD-091-001`|通常の三つのCLIで生成した架空会話を読み、固定観測例と実物の契約を照合。tool・中断・親UUID分岐・末尾途中・曖昧な対応を誤って往復にしない|
|`IT-091-002`|`AD-091-002`|実SQLiteでreadonly確認・人物分離・重複/競合・途中失敗と再実行。原文と索引の片方だけが確定せず、従来の記憶/名乗り/状態が不変。元ファイル移動と同文別会話、別セッションの同じstep番号を区別。A取込後Bを追記してもA不変でBだけ追加|
|`IT-091-003`|`AD-091-003`|共有検索を自動提示とMCPから呼び、合計件数・予算・出典表示を確認。通常記録と同番号の外部記録で参照が混ざらず、他人物で取得できない。A取込後Bを追記した前後を取得できる|
|`IT-091-004`|`AD-091-004`|Entryで保存した設定と固定人物が取り込み/夢/対話まで同じ。内部呼出しで再帰せず、非TTY・中断・並行プロセス・上限・ログ/DB失敗を実際の境界で確認|

## 対象外

手動取り込みと通常起動時の一回の準備を作る。常駐監視、全アカウントの一括自動取り込み、画像・添付本文、GUI、既存記憶の削除、要約からの会話再構成は作らない。検証には架空の会話と使い捨ての宿りを使う。
