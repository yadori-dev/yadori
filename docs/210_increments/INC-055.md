# INC-055 気持ちが会話で動き、時間とともに薄れる

| 項目 | 内容 |
|---|---|
| Issue | #55 気持ちが会話で動き、時間とともに薄れるようにする |
| PR | [#58](https://github.com/yadori-dev/yadori/pull/58) |
| 選んだ受入基準 | `AC-004` 一度の会話で気持ちが動き、会話の後も残り、時間で薄れる |

## 体験の変化

話す人が端末で話すと、返事のあとに「この往復で気持ちがどう動いたか」と「いまの値」が一行出る。会話を終えてしばらく置いて話しかけると、前置きに渡る気持ちは経過時間ぶん薄れている。宿りは今の気持ちを踏まえて応対する。

薄く作る。軸は一本（−1 沈む ↔ +1 明るい）。一往復ごとの動き（いつ、どの往復で、どちらへどれだけ、なぜ）を積み、現在値は動きと経過時間から計算で求める（[ADR-007](../010_decisions/ADR-007-気持ちと性格を上書きせず出来事から求める.md)）。動きの量は応対を作る AIモデルが返事と一緒に一行で答える。薄れ方は半減期 6 時間の指数で、値は測っていない仮置きである（[未決事項](../110_requirements/05-未決事項.md)「気持ちが薄れる速さ」）。実際に使って直す。測る手順と下書きの手順は気持ちを動かさない。

## 入口の例

```console
> 三時間やってもテストが通らない
そら: それはしんどいですね。どこで詰まっていますか。
（気持ち: -0.3 一緒に困っている → いま -0.30）
> やっと通った
そら: よかった！何が原因でしたか。
（気持ち: +0.5 ほっとした → いま +0.20）
```

## 手段の候補

- `IDEA-055-001`: 動きの量を、返事とは別にもう一度 AIモデルへ問う。往復ごとに呼び出しが二倍になる。採らない
- `IDEA-055-002`: 動きの量を、返事の文章から手元の規則（語の有無）で決める。AIモデルを使わないが、規則が粗く、返事の口調と食い違う。採らない
- `IDEA-055-003`: 応対を作る呼び出しの中で、返事の末尾に決まった形の一行（`【気持ち】<数> <一言>`）を書かせ、手元で切り出す。呼び出しは増えず、`ADR-007` の「AIモデルが決めるのは今回どう動いたかだけ」に収まる。**採る。** 一行が無ければ動きなし（0）として扱い、返事はそのまま渡す

## 要件とシステムテスト

| 要件と根拠 | 必要な振る舞い |
|---|---|
| `SPEC-055-001`（`AC-004`）一往復で気持ちが動き、動きが残る | 端末で一往復すると、その往復の動き（−1.0〜+1.0 の数と一言）と、いまの値が返事の後に一行出る。動きは保存先に、いつ・どの往復・どちらへどれだけ・なぜ、として積まれ、上書きされない。応対を作る AIモデルが返す動きの印の行は返事の文章から取り除く（数が読めなくても取り除く）。印の行が無い、または数が読めなければ、動きは 0 で理由は「動きなし」になる（0 の動きも積む。いつ何が起きたかを途切れさせない）。印の行しか無く返事が空なら、応対を作れなかったとして覚えない |
| `SPEC-055-002`（`AC-004`）時間で薄れ、薄れ方は計算で決まる | いまの値は、積まれた動きのそれぞれを経過時間で半減期 6 時間の指数で薄めた和で、−1 と +1 の間に収める。同じ動きの並びと同じ時刻からは同じ値になり、AIモデルを呼ばない。次に話しかけたとき、前置きに渡る気持ちはその時点で求めた値である |
| `SPEC-055-003`（`AC-004`）今の気持ちが応対に渡る | 応対を作る前置きに、いまの気持ちの値と言葉（沈んでいる・落ち着いている・明るい）が入る。測る手順と下書きの手順（覚えるだけの呼び手）は動きを積まない |

### 個々のシステムテスト

| テスト | 対応 | 観点 | 入力 | 期待する結果 |
|---|---|---|---|---|
| `ST-055-001` | `SPEC-055-001` | 端末で動きが見え、積まれる | 動きの一行を返す差し替えの声で二往復する。次に、一行を返さない声で一往復する | 各返事の後に「（気持ち: <数> <一言> → いま <値>）」が出る。保存先の動きが三件積まれ、三件目は動き 0・理由「動きなし」で、返事に一行が混ざらない |
| `ST-055-002` | `SPEC-055-002` | 薄れ方が計算で決まる | 動き +0.5 を積んだ直後、6 時間後、12 時間後の時刻で思い出す。同じ入力で二度求める | 値が +0.50、+0.25、+0.125 になり、二度とも同じ。AIモデルの呼び出しは起きない |
| `ST-055-003` | `SPEC-055-003` | 前置きに気持ちが渡り、測る側は動かさない | 受け取った前置きを記録する差し替えの声で一往復する。次に、測る手順で評価セットを測る | 前置きに気持ちの値と言葉がある。測った後の使い捨ての記憶に動きは無い |

## 設計と結合テスト

### 設計判断

| 設計判断 | 実現する要件 | 構造と責務 |
|---|---|---|
| `AD-055-001` 動きは保存先の一つの表に積み、気持ちの現在値は domain が動きから求める | `SPEC-055-001` `SPEC-055-002` | domain の memory に動き（`Shift`。いつ、どちらへどれだけ、なぜ、どの往復か）と、気持ち（`Mood`。値と、値を言葉にしたもの）を置く。現在値を求める規則（半減期の指数の和、−1〜+1 に収める）は `Mood.from_shifts(shifts, now, half_life)` として domain が持つ。保存先の口（`Memories`）に `record_shift` と `shifts(dweller_id)` を足し、SQLite は `shift` 表（`dweller_id`、`at`、`delta`、`cause`、`episode_id`）、手元の並びも同じ形で持つ。種類の列は今は持たない。性格（#56）は同じ表を長い半減期で読むので、表を増やさない。半減期は domain の定数 `MOOD_HALF_LIFE` に置き、説明に仮置きの理由を書く |
| `AD-055-002` 動きは「覚える」の口が積み、思い出しは気持ちを添えて返す | `SPEC-055-001` `SPEC-055-003` | 覚える口（`Conversation.remember`）に任意の引数で動き（`Moved`。どちらへどれだけ、なぜ）を受け、原文を書いた後にその往復の番号と共に動きを積む。渡されなければ積まない。測る手順と下書きの手順は渡さないので動かない。思い出す口は、動きを読んで今の気持ちを求め、思い出したこと（`Recollection`）に `mood` として添える。今の気持ちだけを読む口 `mood` を会話の口に足すが、記憶を動かす入口は思い出すと覚えるの二つのまま（[ADR-012](../010_decisions/ADR-012-会話の入口を思い出すと覚えるの二つに分ける.md)） |
| `AD-055-003` 動きの量は声が返事と一緒に返し、切り出しは声の実装が持つ | `SPEC-055-001` `SPEC-055-003` | 声の口（`Voice.speak`）の返りを文字列から `Spoken`（返事、動き）にする。対話する道具の声は、前置きに今の気持ちの値と言葉を入れ、話しかける文に「返事の最後に `【気持ち】<−1.0〜+1.0> <一言>` を一行だけ書く」と添える。返事の末尾のその一行を切り出して動きにし、無ければ動き 0・理由「動きなし」。切り出しの規則は声の実装に閉じ、一往復の手順（`Turn`）は `Spoken` を受けて覚える口へ動きを渡し、応対の結果（`Response`）に動きと動いた後の気持ちを載せる。端末はそれを一行で書く |

### 個々の結合テスト

| テスト | 対応 | 観点 | 入力 | 期待する結果 |
|---|---|---|---|---|
| `IT-055-001` | `AD-055-001` | 動きが積まれ、現在値が計算で決まり、保存の実装で変わらない | 二つの保存の実装に同じ動きを同じ順で積み、同じ時刻で気持ちを求める。動きが無いとき、和が 1 を超えるときも求める | 二つの実装で同じ動きの並びと同じ値が返る。動きが無ければ 0。超えれば +1 に収まる。積んだ動きは上書きされず件数が増える |
| `IT-055-002` | `AD-055-002` | 覚えるが動きを積み、思い出すが気持ちを添える | 動き付きで覚え、動き無しで覚え、思い出す | 動きは一件だけ積まれ、その往復の番号を持つ。思い出したことの気持ちがその動きから求めた値になる |
| `IT-055-003` | `AD-055-003` | 声の切り出しと、一往復の受け渡し | 道具の代わりに、末尾に動きの一行がある返事／無い返事／数が範囲外の返事を返すものを差し込んで声を呼ぶ。次に、決まった動きを返す差し替えの声で一往復を通す | 一行がある返事は動きと一言が取れ、返事から一行が消える。無ければ 0 と「動きなし」。範囲外は −1〜+1 に収める。一往復の結果に動きと動いた後の気持ちが載り、覚えた往復の番号で動きが積まれている |
