# INC-078 agy を宿りとして起こす

結果のPR: [#81](https://github.com/yadori-dev/yadori/pull/81)

対応する要求は [Issue #78](https://github.com/yadori-dev/yadori/issues/78)。選んだ受入基準は `AC-001`（指示しなくても前の会話を踏まえる）、`AC-003`（道具を変えても同じ相手として続く）。

## 要件とシステムテスト

| 識別子 | 内容 |
|---|---|
| `SPEC-078-001` | 導入・ログイン済みの Antigravity CLI を `yadori agy` から起こす。宿りの名乗り、現在の状態、直近と関係する記憶、夢を発話前に渡す。作業場所で既存のファイルを読み、検索・ファイル編集・端末命令を使える。承認を要する操作では agy の確認を受けられる。ヘルプへ入口を載せる。未導入の場合は起動せず、認証と信頼の確認は agy 自身に任せる |
| `ST-078-001` | `SPEC-078-001` 使い捨ての宿りと作業場所で実 agy を起こし、架空の会話、ファイル読み取り、終了を通す。Claude Code・Codex と agy のそれぞれ双方向で、対象の架空の記憶の後に無関係な往復を8件以上置き、新しい起動の直近6件には答えが無いこと、対象が関係する記憶として選ばれることを確認する。答えを含めない質問への応対がその記憶と共通の名前・話し方・気持ちを踏まえることを観測する。未導入・未認証・非対応の版や環境では理由と対処を確認し、ヘルプを読む。使い捨てファイルの検索と安全な端末命令の結果を確認する。承認が必要なファイル変更を許可・拒否して結果を確かめる |
| `SPEC-078-002` | 主担当の正常に完了した一往復だけを原文と気持ちの組で一度だけ残す。同文の別発話と同じ通知の再送を区別する。途中の道具呼び出し、下位担当、中断した未完は確定しない |
| `ST-078-002` | `SPEC-078-002` 実物から採った入力をフックの入口へ渡し、複数の呼び出し、同文の別発話、再送、異なる再送、中断、下位担当の通知を比較する。正常停止の実物の通知と記録を通常検査から分けて照合する |
| `SPEC-078-003` | 文脈準備に失敗したら新しい発話をモデルへ送らない。保存に失敗した完成済みの往復は専用領域へ残して警告し、次回の会話より先に再試行する。未確認の記録は勝手に確定・削除しない |
| `ST-078-003` | `SPEC-078-003` 思い出す処理と保存先をそれぞれ失敗させ、前者はモデル未呼び出し、後者は原文保全と再試行後の一件保存を確認する。読み取れない回復記録がある場合は起動を断る |
| `SPEC-078-004` | 普段の設定・履歴を使用し、宿りの作業状態だけを一回の起動へ分ける。通常の認証と承認を agy に任せる。共通の起動要件は [INC-102](INC-102.md) に従う |
| `ST-078-004` | `SPEC-078-004` 通常の設定・指示・履歴を使い捨て環境に置き、宿り経由でも使えること、通常の履歴が終了後に残ることを確認する。回復用の原文は保存まで保持する |

## 対象外

Gemini CLI、IDE、遠隔操作、普段の agy の過去ログ取り込み、評価セットへの agy ログ取り込み、自発的な発話。通常の拡張・履歴・再開は agy 自身の機能を使う。思い出す条件と保存形式は変えない。

## 設計と結合テスト

| 識別子 | 内容 |
|---|---|
| `IDEA-078-001` | 採用: 追加ディレクトリからフックと記憶の MCP を読み込ませ、普段の環境を保つ |
| `IDEA-078-002` | 不採用: 普段の設定を書き換えて終了時に戻す。並行起動と異常終了で普段の人格・履歴へ混入する |
| `IDEA-078-003` | 不採用: 独自の対話画面で agy の一回実行を包む。通常の agy の作業画面を使う要求から外れる |
| `AD-078-001` | `SPEC-078-001` `SPEC-078-004` 通常の agy を追加ディレクトリ付きで起こす。設定・履歴を差し替えず、通知処理の状態だけを宿りへ置く。内部の判定呼び出しには隔離を残す |
| `IT-078-001` | `AD-078-001` 無害な通常設定・履歴・指示を持つ起動で、環境と引数の保持、履歴の継続を確認する。実 agy でも追加ディレクトリのフックが実行されることを確認する |
| `AD-078-002` | PreInvocation が実 transcript の主担当の最新 USER_EXPLICIT を取り、会話IDとstep_indexで発話を識別する。正常な Stop の最終返事だけを会話の記憶へ渡す。文脈の組み立て・気持ちの取り出し・原文と気持ちの保存には既存の CompanionWords と Conversation を使う |
| `IT-078-002` | `AD-078-002` 実物の transcript とフック入力を固定し、道具の複数回実行、同文の別発話、再送、中断、違う会話、異なる原文の再送を入口から照合する。実物との契約テストで形式差を検出する |
| `AD-078-003` | フックの失敗を無視する agy の挙動に対し、フック命令の内側に20秒の期限と2秒後の強制終了を置き、agy側の30秒の期限より先に処理を終える。失敗・時間切れなら命令の親である当該 agy へ TERM を送り、新しい呼び出しを止める。完成した未保存の往復は agy 専用の回復記録へ先に書き、正常保存まで消さない。読み取り失敗を無しとして扱う既存 PendingStore と、古い記録を消す StaleSessionCleaner はここへ流用しない。同じ出典を Conversation.remember へ再送し、保存直後の中断でも二重にしない。正常終了でも未保存記録があれば保持する。起動時は施錠されていない回復記録を先に再試行し、壊れた記録なら起動を断る |
| `IT-078-003` | `AD-078-003` 実 agy にフック失敗と処理のハングを与え、どちらもモデルが呼ばれず終了することを確認する。保存先の失敗とプロセス中断で回復記録を残し、復旧後の再送で一度だけ保存する。保存成功直後・回復記録削除直前の中断を再現し、再送で二重保存せず、終了状態0でも未保存記録が消えないことを確かめる。回復記録を意図的に壊すと新しい会話が始まらないことを確認する |

起動と回復の判断は [ADR-022](../010_decisions/ADR-022-agyの設定と履歴をLinuxの起動ごとに分ける.md)。

一次仕様: [agy のフック](https://antigravity.google/docs/hooks/)、[認証](https://antigravity.google/docs/cli/install/)、[設定](https://antigravity.google/docs/cli/settings/)。対応する実物の版と入力は契約テストへ固定する。
