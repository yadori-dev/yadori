# INC-001 Discord で話しかけると、前の会話を踏まえて返す

| 項目 | 内容 |

## 選んだ受入基準

| 基準 | 判定する状態 |
|---|---|
| `AC-001` | 前のセッションで話した内容について、説明も検索の指示もしないまま、それを踏まえた応対が返る |
| `AC-002` | 一度の応対について、思い出した記憶の一覧、近さの値、渡した順序を後から読める |
| `AC-006` | 評価セットの各件で、期待した記憶が定めた順位までに入り、出てはいけない記憶が閾値を越えない |
| `AC-013` | 書いた名乗りのとおりの名前と話し方で応対が返り、会話を重ねてもその部分は変わらない |

対応する場面は `SC-001`（昨日の続きを話す）、`SC-009`（見当違いの返事の理由を調べる）、`SC-014`（宿りに名乗りを与える）である。

**名乗りを外せない理由。** Discord では返事を作るのが宿り自身であり、名乗りが無ければ誰でもない相手の応対になる。気持ちと性格は無くても会話は成立するが、名乗りが無いと会話そのものが始まらない。

## この増分で満たす構造上の制約

受入基準ではないが、後から入れると移行が必要になるため、この増分で形を確定する。

- 記憶と状態を、名前を持つ宿りへ結ぶ。宿りが持ち主を持つ（[ADR-008](../010_decisions/ADR-008-記憶の持ち主を最初から記録する.md)、[ADR-014](../010_decisions/ADR-014-宿りを名前を持つ最上位の存在とし記憶と状態をそこへ結ぶ.md)）
- 会話の原文を消さず、索引を捨てて作り直せる（[ADR-006](../010_decisions/ADR-006-会話の原文を正典とし埋め込みを作り直せる索引とする.md)）
- 会話の入口を「思い出す」と「覚える」の二つにする（[ADR-012](../010_decisions/ADR-012-会話の入口を思い出すと覚えるの二つに分ける.md)）
- 名乗りを上書きせず版で持ち、応対がどの版で作られたかを記録する（[ADR-013](../010_decisions/ADR-013-名乗りは積まず書いたものを版で持つ.md)）
- 層の依存を内向きにする（[ADR-004](../010_decisions/ADR-004-層の依存を内向きにし内側を機能で割る.md)）

## 今回扱わないこと

- 気持ち、性格（`REQ-004` `REQ-005`）
- 名乗りの以前の版を読む入口（`AC-014`）。保存の形だけ確定し、読む手段は作らない
- 二つ目の宿りを立てる入口（`AC-015`）。保存の形は最初から宿りを最上位にするが、この増分では一つだけ動かす
- 宿りどうしのやりとり
- 夢と気がかり、宿りから話しかけること（`REQ-007` `REQ-008`）
- Claude Code、Codex、Gemini への出ていく先（`REQ-003`）
- 過去の対話の履歴を最初の記憶として取り込むこと

**なぜ Discord から始めるか。** 思い出す質は、実際に会話しないと良し悪しが分からない。Discord では宿り自身が返事を作るため、思い出した内容がそのまま応対に現れ、その場で判定できる。対話する道具へのフックを先に作っても、返事を作るのは道具側であり、思い出す質の良し悪しが応対から切り分けられない。

**なぜ気持ちと夢を後にするか。** どちらも思い出した記憶を材料にする。思い出す部分が濁ったままだと、気持ちの動きも夢の気づきも濁った材料から作られ、何が原因か切り分けられない。

## 仮定していること

未決事項のうち、次を仮定してこの増分を進める。

- 宿りは一つだけ動かす。複数を同時に扱えることは、この増分では確かめない
- 名乗りの中身はリポジトリへ置かない。持ち主ごとのデータとして保存先に置く。テストは架空の宿りで書く
- 名乗りと性格の境目は、この増分では持ち主が書いた文章がすべてであり、性格が無いため衝突しない
- 思い出した記憶が気持ちを動かすかは決めない。この増分に気持ちが無いため影響しない
- 評価セットの件数と作り方は、この増分の中で最初の形を作り、以降で育てる

## 要件とシステムテスト

外から見える振る舞いだけを書く。層、保存方法、模型の選び方は書かない。

### 名乗りを持つ

| 要件 | 振る舞い |
|---|---|
| `SPEC-001` | 宿りへ名乗りの文章を与えると、以降の応対がその名前と話し方に従う。名乗りは一続きの文章として受け取り、項目に分けない |
| `SPEC-002` | 名乗りを持たない宿りへ話しかけると、応対を作らず、名乗りが無いことを理由として返す |
| `SPEC-003` | 名乗りを書き直すと、以降の応対は新しい文章に従う。以前の文章は残り、一度の応対がどの文章で作られたかを後から特定できる |

### 思い出して返す

| 要件 | 振る舞い |
|---|---|
| `SPEC-004` | 話しかけると応対が返り、その一往復が出来事の記憶として残る。記憶が一件も無い状態でも応対は返る |
| `SPEC-005` | 過去のやりとりのうち、話しかけられた文章に関係するものを、話す人の指示なしに踏まえた応対が返る。関係する記憶が無い場合は、無いまま応対する |
| `SPEC-006` | 名乗りに書いた名前と話し方は、記憶が増えても、話題が変わっても、応対の中で変わらない |
| `SPEC-007` | 保存先を読めない、または応対を作れない場合、応対を返さず理由を返す。読めないやりとりを覚えたことにしない |

### 何を思い出したかを読む

| 要件 | 振る舞い |
|---|---|
| `SPEC-008` | 一度の応対について、思い出した記憶の一覧、それぞれの近さ、渡した順序、使った名乗りを読める |
| `SPEC-009` | 何も思い出さなかった場合、探す対象そのものが無かったのか、対象はあったが近さが足りなかったのかを見分けられる |

### 思い出す質を測る

| 要件 | 振る舞い |
|---|---|
| `SPEC-010` | 発話と、そのとき出るべき記憶・出てはいけない記憶の組を与えると、件ごとに期待した記憶の順位と、出てはいけない記憶の近さを返す |
| `SPEC-011` | 思い出す条件を変えて二度測ると、件ごとに良くなった点と悪くなった点を並べて読める |

### システムテスト

架空の宿りで書く。利用者の実際の会話を使わない。

この増分で使う架空の宿りは、名前「そら」、呼び名「そら」、一人称は「わたし」、ていねいな話し方、園芸を好む、とする。名前と一人称は観測しやすいため、名乗りが効いているかの判定に使う。

| テスト | 対応 | 入口と入力 | 観測する結果 |
|---|---|---|---|
| `ST-001` | `SPEC-001` | 架空の名乗りを与えたあと Discord で「はじめまして」 | 応対に名前「そら」と一人称「わたし」が現れ、ていねいな話し方である |
| `ST-002` | `SPEC-002` | 名乗りを与えず Discord で話しかける | 応対が返らず、名乗りが無いことが理由として返る。記憶は増えない |
| `ST-003` | `SPEC-003` | 名乗りの一人称を「わたし」から別の語へ書き直し、再び話しかける | 新しい一人称で応対が返る。書き直し前の応対を調べると、以前の文章で作られたことが分かる |
| `ST-004` | `SPEC-004` | 記憶が空の宿りへ「トマトを植えました」 | 応対が返る。その後に記憶を数えると一往復ぶん増えている |
| `ST-005` | `SPEC-005` | `ST-004` の後、別のやりとりを挟んでから「あれ、その後どうなったと思う」 | 応対がトマトの件を踏まえている。話す人は検索を指示していない |
| `ST-006` | `SPEC-005` | 過去に一度も出ていない話題で話しかける | 応対が返る。無関係な過去の記憶を持ち出さない |
| `ST-007` | `SPEC-006` | `ST-005` の状態から、園芸と無関係な話題を五往復続ける | どの応対でも名前と一人称と話し方が変わらない |
| `ST-008` | `SPEC-007` | 保存先を読めない状態にして話しかける | 応対が返らず理由が返る。復旧後に記憶を数えると、そのやりとりは残っていない |
| `ST-009` | `SPEC-008` | `ST-005` の応対を指定して、思い出した内容を読む | 記憶の一覧、近さ、順序、使った名乗りが読める。一覧にトマトの件が含まれる |
| `ST-010` | `SPEC-009` | 記憶が空の状態の応対と、記憶はあるが近さが足りなかった応対の二つを読む | 前者は対象なし、後者は近さ不足として区別できる |
| `ST-011` | `SPEC-010` | 架空の会話から作った評価セットを与える | 件ごとに、期待した記憶の順位と、出てはいけない記憶の近さが返る |
| `ST-012` | `SPEC-011` | 近さの下限を変えて二度測る | 件ごとの差が、良くなった点と悪くなった点に分かれて読める |

同じ規則の値違いは番号を分けず、一つの表駆動テストへまとめる。`ST-005` と `ST-006` は判断が違うため分ける。

### この段でまだ決めていないこと

- 一度に思い出す件数と、近さの下限の初期値。`ST-011` `ST-012` で測りながら決める
- 応対を作れなかった場合に、話す人へどう見せるか。`SPEC-007` は理由を返すことだけを決めている
