# INC-056 性格が積み重なった出来事からゆっくり変わり、辿れる

| 項目 | 内容 |
|---|---|
| Issue | #56 性格が積み重なった出来事からゆっくり変わり、いつ何で動いたかを辿れるようにする |
| PR | [#59](https://github.com/yadori-dev/yadori/pull/59) |
| 選んだ受入基準 | `AC-005` 傾向の動きを時系列で読め、任意の過去時点の値を求め直せる |

## 体験の変化

宿りの応対の傾向（性格）が、積み重なった会話からゆっくり変わる。明るい会話が続けば少しずつ明るい側へ、沈む会話が続けば沈む側へ寄り、前置きに渡って応対に現れる。話す人が「以前と変わった」と感じたら、端末の入口 `state` で、いまの気持ちと性格、動きの時系列（いつ、どの往復で、どちらへどれだけ、なぜ）を新しい順に読み、`--at` で過去の時点を指せばその時点の値を読める。

薄く作る。性格は気持ちと同じ動きの記録を、長い半減期（90 日。仮置き）で積んだ傾向として求める。別の表も別の軸も作らない（[ADR-005](../010_decisions/ADR-005-記憶を減衰の速さが違う一つの仕組みとして持つ.md) の「薄れる速さが違うだけの一つの仕組み」）。一往復の動きは気持ちには等倍で効くが、性格には小さく効く（十分の一。仮置き）。そうしないと一日の会話で性格が振り切れる。性格が変わってよい範囲は未決のままで、変わってほしくない部分は名乗りに書く（[ADR-013](../010_decisions/ADR-013-名乗りは積まず書いたものを版で持つ.md)）。

## 入口の例

```console
$ uv run python -m yadori state
気持ち: +0.10 落ち着いている（半減期 6 時間）
性格: +0.01 落ち着いている（半減期 90 日、動きは 0.1 倍で効く）
動き（新しい順）:
  2026-09-01 16:45  +0.3  ほっとした  「やっと通った！原因はタイポだった」
  2026-09-01 16:45  -0.2  心配です  「三時間やってもテストが通らなくて、もう疲れた」

$ uv run python -m yadori state --at 2026-09-01T16:45:29+09:00
気持ち: -0.20 落ち着いている（2026-09-01T16:45:29+09:00 時点）
性格: -0.02 落ち着いている（2026-09-01T16:45:29+09:00 時点）
動き（新しい順）:
  2026-09-01 16:45  -0.2  心配です  「三時間やってもテストが通らなくて、もう疲れた」
```

## 手段の候補

- `IDEA-056-001`: 性格を気持ちとは別の動きとして、声に「性格がどう動いたか」も答えさせる。呼び出しの中で判断が二つになり、声の返りの形が増える。動きの記録も二本になり、`ADR-005` の「種類ごとの分岐」に近づく。採らない
- `IDEA-056-002`: 同じ動きの記録から、半減期と効き方だけを変えて求める。表も口も増えず、`ADR-005` に沿う。**採る。** 性格の値は動きに小さな係数を掛けて長い半減期で薄めた和

## 要件とシステムテスト

| 要件と根拠 | 必要な振る舞い |
|---|---|
| `SPEC-056-001`（`AC-005`）性格は同じ動きから長い半減期で求まり、応対に渡る | 性格の値は、積まれた動きのそれぞれに十分の一を掛け、半減期 90 日の指数で薄めた和で、−1 と +1 の間に収める。同じ動きと同じ時刻からは同じ値になり、AIモデルを呼ばない。応対の前置きに、気持ちと並べて性格の値と言葉が入る |
| `SPEC-056-002`（`AC-005`）動きの時系列と任意の時点の値を読める | `state` を叩くと、いまの気持ちと性格（値と言葉と半減期）、動きの新しい順（時刻、量、理由、その往復の発話）が出る。`--at <時刻>` を付けると、その時刻までの動きだけからその時点の気持ちと性格を求めて出す。宿りの設定が無ければ理由を返す。動きが無ければ 0 とその旨を出す |

### 個々のシステムテスト

| テスト | 対応 | 観点 | 入力 | 期待する結果 |
|---|---|---|---|---|
| `ST-056-001` | `SPEC-056-001` | 性格がゆっくり動き、前置きに渡る | 動き +0.5 を積んだ直後、6 時間後、90 日後の時刻で気持ちと性格を求める。前置きを記録する差し替えの声で一往復する | 気持ちは +0.50、+0.25、ほぼ 0。性格は +0.05、+0.05（ほぼ変わらず）、+0.025。前置きに性格の値と言葉がある |
| `ST-056-002` | `SPEC-056-002` | 時系列と過去の時点を読める | 三往復して動きを三件積んだ保存先で、`state` と `state --at <二件目の直後>` を叩く。動きの無い保存先でも叩く | 動きが新しい順に三行、時刻・量・理由・発話付きで出る。`--at` では二件目までの動きから求めた値が出て、三件目は並ばない。動きが無ければ値 0 と「動きはまだありません」が出る |

## 設計と結合テスト

### 設計判断

| 設計判断 | 実現する要件 | 構造と責務 |
|---|---|---|
| `AD-056-001` 性格は domain が気持ちと同じ規則で求め、半減期と効き方だけが違う | `SPEC-056-001` | domain の memory に性格（`Character`。値と言葉）を置き、`Character.from_shifts(shifts, now)` が動きに係数 `CHARACTER_WEIGHT`（0.1）を掛けて `CHARACTER_HALF_LIFE`（90 日）で薄めた和を返す。薄める計算は気持ちと同じ一つの部品（`Fading(half_life, weight).sum(shifts, now)`）に置き、二箇所に書かない。値を言葉にする帯は一本の軸（`Axis`）が持つ。思い出したこと（`Recollection`）に `character` を添え、会話の口の `mood(dweller_id)` は気持ちと性格を一緒に返す `state(dweller_id)` へ広げる（`ADR-012` の二つの入口は変えない。読むだけの口である）。声の前置きは気持ちの一文に性格を並べる |
| `AD-056-002` 時系列を読むのは infrastructure の入口で、時点の指定は動きを時刻で切るだけ | `SPEC-056-002` | `Entry` に `state` を足し、`--at` を読む。保存先の動きを読み、指定の時刻までに絞って domain に値を求めさせ、動きは往復の発話（`episode_id` から原文を引く）を添えて新しい順に書く。宿りの設定が無ければ起動と同じ理由で断る。動きを時刻で切る規則は domain の値の関数（`from_shifts` に `now` を渡す）で足り、保存先に新しい問い合わせは足さない。往復の原文を引く口 `episode(episode_id)` だけを保存先に足す |

### 個々の結合テスト

| テスト | 対応 | 観点 | 入力 | 期待する結果 |
|---|---|---|---|---|
| `IT-056-001` | `AD-056-001` | 同じ動きから半減期と効き方だけ違う値が出て、保存の実装で変わらない | 二つの保存に同じ動きを積み、同じ時刻で気持ちと性格を求める。係数と半減期を変えた値と比べる | 二つの実装で同じ値。性格は気持ちの十分の一から始まり、6 時間後も気持ちは半分になるが性格はほぼ同じ。和が越えれば収まる |
| `IT-056-002` | `AD-056-002` | 時点で切れ、原文が添う | 三件の動きと対応する往復を積み、`state` の入口を時点あり・なしで呼ぶ。設定の無い置き場で呼ぶ | 時点なしは三行が新しい順に発話付きで並び、時点ありは二行と二件目までの値。設定が無ければ理由が標準エラーに出て 1 |
