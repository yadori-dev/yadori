# 眠っている間に記憶が固まること（記憶の固定 memory consolidation／システム固定 systems consolidation）

## 何をするものか

日中に覚えたことが、眠っている間にもう一度なぞられ、しまわれる場所が移り、後まで残る形へ変わっていく、という説明である。

## 一次情報

### 眠りの中で、起きていたときの発火の並びが繰り返される（再生 replay）

- Wilson MA, McNaughton BL. "Reactivation of hippocampal ensemble memories during sleep." *Science* 265:676-679, 1994. doi:[10.1126/science.8036517](https://doi.org/10.1126/science.8036517) — **全文確認。** ラット 3 匹の海馬 CA1 から 50〜100 個の細胞を同時記録した。走行中に同じ場所で一緒に発火した細胞の組は、その後の眠りでも一緒に発火しやすくなった（走行前の眠りと比べて有意に増加）。走行中に活動していても場所が重なっていない組では増えなかった。増えた相関はおよそ 12 分の時定数で薄れ、徐波睡眠中の同期した短い発火のかたまり（鋭波リップル sharp-wave ripple、眠りの深いときに海馬で起きる 0.1 秒ほどの一斉発火）の最中に特に大きかった。

- Girardeau G, Benchenane K, Wiener SI, Buzsáki G, Zugaro MB. "Selective suppression of hippocampal ripples impairs spatial memory." *Nature Neuroscience* 12:1222-1223, 2009. doi:[10.1038/nn.2384](https://doi.org/10.1038/nn.2384) — **要旨のみ確認。本文は未読。** 学習後の眠りの間だけ鋭波リップルを選んで消すと、空間課題の成績が落ちた。再生が「起きているだけ」ではなく成績に効いていることを示した実験である。

### 覚えたてのものが海馬から新皮質へ移るという枠組み

- McClelland JL, McNaughton BL, O'Reilly RC. "Why there are complementary learning systems in the hippocampus and neocortex: Insights from the successes and failures of connectionist models of learning and memory." *Psychological Review* 102(3):419-457, 1995. doi:[10.1037/0033-295X.102.3.419](https://doi.org/10.1037/0033-295X.102.3.419) — **要旨のみ確認。本文は未読。** 相補学習系（complementary learning systems、速く覚える仕組みとゆっくり覚える仕組みを二つ持つという考え）。新しいことはまず海馬側の結合の変化として速く蓄えられ、それが新皮質で繰り返し呼び戻される。新皮質の結合は一回の呼び戻しにつき少しずつしか変わらず、その積み重ねが古い記憶になる。学習を少しずつ、かつ他の項目と混ぜ合わせて（interleaved）行わないと、それまでに覚えた構造が壊れる、と述べている。

- Diekelmann S, Born J. "The memory function of sleep." *Nature Reviews Neuroscience* 11(2):114-126, 2010. doi:[10.1038/nrn2762](https://doi.org/10.1038/nrn2762) — **要旨のみ確認。本文は未読。** 徐波睡眠（深い眠り）では、遅い波・紡錘波・リップルという三つのリズムが噛み合って、海馬に依る記憶の呼び戻しと新皮質への配り直しを整える。レム睡眠では、局所の可塑性に関わる遺伝子の働きが上がり、皮質側での固定を後押しする、としている。

- Rasch B, Born J. "About sleep's role in memory." *Physiological Reviews* 93(2):681-766, 2013. doi:[10.1152/physrev.00032.2012](https://doi.org/10.1152/physrev.00032.2012) — **要旨のみ確認。本文は未読**（出版社サイトと大学リポジトリのいずれもボット遮断で本文へ到達できなかった）。要旨では、初期の理論が「眠りは邪魔が入らないから記憶が守られる」という受け身の役割を置いていたのに対し、現在の理論は眠りに能動的な役割を置く、と整理している。固定は最近覚えたものの呼び戻しから始まり、徐波睡眠中に起き、長期の記憶へ組み込むために表現そのものを作り変える。続くレム睡眠が作り変わったものを安定させる、としている。

- Klinzing JG, Niethard N, Born J. "Mechanisms of systems memory consolidation during sleep." *Nature Neuroscience* 22:1598-1610, 2019. doi:[10.1038/s41593-019-0467-3](https://doi.org/10.1038/s41593-019-0467-3) — **要旨のみ確認。本文は未読。** 上の枠組みを「能動的システム固定（active systems consolidation）」と呼び、これが全体的なシナプスの弱め直し（→ [眠っている間に記憶が薄れ整理されること](眠っている間に記憶が薄れ整理されること.md)）の中に埋め込まれた過程だとする。固定を経た記憶は、細部を落として要点だけの形（gist-like）へ質的に変わる、と述べている。

### 人で、狙った記憶だけを眠りの中で呼び戻す実験

- Rasch B, Büchel C, Gais S, Born J. "Odor cues during slow-wave sleep prompt declarative memory consolidation." *Science* 315:1426-1429, 2007. doi:[10.1126/science.1138581](https://doi.org/10.1126/science.1138581) — **要旨のみ確認。本文は未読。** 学習中に嗅がせた匂いを徐波睡眠中に再び嗅がせると、言葉で言える記憶の保持が良くなった。レム睡眠中・覚醒中では効かず、学習時に匂いを出していなかった場合も効かなかった。

- Hu X, Cheng LY, Chiu MH, Paller KA. "Promoting memory consolidation during sleep: A meta-analysis of targeted memory reactivation." *Psychological Bulletin* 146(3):218-244, 2020. doi:[10.1037/bul0000223](https://doi.org/10.1037/bul0000223) — **要旨のみ確認。本文は未読。** 91 実験・212 の効果量・のべ 2,004 人をまとめたメタ分析（複数の研究の結果を統計的に足し合わせる手法）。全体で Hedges' g = 0.29（95% 信頼区間 0.21〜0.38）。効いたのはノンレム睡眠の段階 2 と徐波睡眠だけで、レム睡眠中と覚醒中では効果が見られなかった。

## 限界

- **Wilson & McNaughton はラット 3 匹の空間課題である。** 著者自身が本文で、増えた相関は「系のどこかの段階での連合的なシナプス変化と整合するが、必ずしも海馬内で起きているとは限らない」と留保し、新皮質や皮質下の経路の変化でも説明できると書いている。人の、意味を伴う出来事や気持ちについて同じことが起きるかは、この実験からは言えない。
- **再生の効果は短い。** 同論文では増えた相関がおよそ 12 分で薄れている。「眠っている間ずっと同じ記憶をなぞり続ける」という像は、この実験からは出てこない。
- **相補学習系は計算モデルから来た枠組みであって、脳の観測から直接導かれたものではない。** 「少しずつ・混ぜて学習しないと既存の構造が壊れる」という主張は、当時のつながりモデル（connectionist model）の性質に依っている。
- **狙った呼び戻し（targeted memory reactivation）の効果量は中程度以下である。** メタ分析の g = 0.29 は小〜中の大きさで、レム睡眠中には効いていない。「眠れば記憶が確実に強まる」ではない。
- **「海馬から新皮質へ移り、海馬は用済みになる」という筋書きには、有力な対立学説がある。**
  - Nadel L, Moscovitch M. "Memory consolidation, retrograde amnesia and the hippocampal complex." *Current Opinion in Neurobiology* 7:217-227, 1997. doi:[10.1016/S0959-4388(97)80010-4](https://doi.org/10.1016/S0959-4388(97)80010-4) — **要旨のみ確認。本文は未読。** 多重痕跡理論（multiple trace theory）。自伝的なエピソードや空間の記憶については、海馬はその記憶が存在するかぎり関わり続ける、とする。
  - Sutherland RJ, Lee JQ, McDonald RJ, Lehmann H. "Has multiple trace theory been refuted?" *Hippocampus* 30:842-850, 2020. doi:[10.1002/hipo.23162](https://doi.org/10.1002/hipo.23162) — **要旨のみ確認。本文は未読。** 多重痕跡理論の中核の予測のうち、支持されているのは一部だけで、「繰り返し呼び戻すたびに海馬側の痕跡が増える」という予測には実験的な裏付けがほとんどない、と評価している。
  - Moscovitch M, Gilboa A. "Systems consolidation, transformation and reorganization: Multiple Trace Theory, Trace Transformation Theory and their Competitors." プレプリント（査読前）, 2021. doi:[10.31234/osf.io/yxbrs](https://doi.org/10.31234/osf.io/yxbrs) — **要旨のみ確認。本文は未読。査読前の原稿である。** 「システム固定」という概念そのものが有用さを終えつつあり、記憶が一生をかけてどう変わるかの研究に置き換えるべきだと主張している。
- 確度: 眠りの中で発火の並びが繰り返されること、およびそれを妨げると成績が落ちることは、**査読を経た研究**として複数ある。一方で「海馬から新皮質へ移る」という筋書きの細部は、**査読を経た研究どうしが対立している**段階にある。
