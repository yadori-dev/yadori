# 人工の対話主体に記憶を持たせる作り（生成エージェント generative agents／階層記憶 hierarchical memory）

## 何をするものか

大きな言語模型を使う受け答えの相手役に、起きた出来事を文章のまま溜めておき、答えるときに必要なぶんだけを選んで渡すことで、長い付き合いでも前を覚えているように振る舞わせる、設計の一群である。

**これは人の理論ではなく、人工の仕組みの設計である。** 学習によって模型の結合そのものを作り変える側の話は [人工の仕組みで眠りをまねること](人工の仕組みで眠りをまねること.md) にある。そこと重なる注意（工学の成果は人の脳の証拠にならない、「眠り」「夢」という呼び名は着想の出どころを示す比喩である）はここで繰り返さない。ここに書くのは、**模型の重みを変えず、何を書き留めて何を読み出すかだけで扱う**側である。

## 一次情報

### 記憶の流れと、新しさ・重要度・関連度の重み付き和（査読を経た研究）

- Park JS, O'Brien JC, Cai CJ, Morris MR, Liang P, Bernstein MS. "Generative Agents: Interactive Simulacra of Human Behavior." *Proceedings of the 36th Annual ACM Symposium on User Interface Software and Technology (UIST '23)*, ACM, 2023. doi:[10.1145/3586183.3606763](https://doi.org/10.1145/3586183.3606763)（arXiv:[2304.03442](https://arxiv.org/abs/2304.03442) v2）— **arXiv 版の全文を確認。ACM の刊行版そのものは有料の壁で未読。** 掲載先が UIST 2023 であることは DBLP の書誌と、共著者の所属機関である Google Research の刊行物一覧の両方で確かめた。**査読を経た国際会議の論文である。**

**記憶の流れ（memory stream）。** 本文の定義は「a list of memory objects, where each object contains a natural language description, a creation timestamp, and a most recent access timestamp」。すなわち一つ一つの記憶は、日常語の文、作られた時刻、最後に読み出された時刻の三つを持つ。もっとも基本の要素は**観測（observation）**で、これは「an event directly perceived by an agent」、つまり本人が直接見聞きした出来事である。

**思い出す仕組み（retrieval）。** 三つの成分の重み付き和で全ての記憶に点を付ける。

- **新しさ（recency）** — 「an exponential decay function over the number of sandbox game hours since the memory was last retrieved. Our decay factor is 0.995」。減っていく速さの係数は **0.995**、数えるのは**作られてからではなく最後に読み出されてからの時間**で、単位は模擬世界の中の時間である。
- **重要度（importance）** — 模型に整数で答えさせる。使った文は全文が載っている。「On the scale of 1 to 10, where 1 is purely mundane (e.g., brushing teeth, making bed) and 10 is extremely poignant (e.g., a break up, college acceptance), rate the likely poignancy of the following piece of memory.」。返る例として「部屋の片付け」が 2、「好きな人を誘う」が 8。**この点は記憶が作られた時点で一度だけ付けられる**（"generated at the time the memory object is created"）。
- **関連度（relevance）** — 記憶の文を数の並びへ写した表現（embedding）を作り、いま置かれている状況の表現との**余弦類似度**（向きの近さ）で測る。

三つを **min-max スケーリング**（最小値と最大値で割り直す）で 0 から 1 の範囲へ揃えたうえで、

> score = α_recency × recency + α_importance × importance + α_relevance × relevance

とし、「In our implementation, all αs are set to 1.」——**重みは三つとも 1**、つまり素の足し算である。上位から、模型に渡せる長さに収まるだけを取る。

**振り返り（reflection）。** 「Reflections are higher-level, more abstract thoughts generated by the agent. Because they are a type of memory, they are included alongside other observations when retrieval occurs.」——**振り返りもまた記憶の一種として同じ流れへ入り、次からは観測と並べて思い出される。**

- **起動の条件** — 「we generate reflections when the sum of the importance scores for the latest events perceived by the agents exceeds a threshold (150 in our implementation). In practice, our agents reflected roughly two or three times a day.」。**日の区切りではなく、直近の出来事の重要度の合計が 150 を超えたとき。** 結果としておよそ一日に2〜3回。
- **何を作るか** — まず**直近 100 件**を模型へ渡し、「Given only the information above, what are 3 most salient high-level questions we can answer about the subjects in the statements?」と問うて**問いを3つ**立てる。次にその問いを検索の問い合わせとして使い（このとき過去の振り返りも候補に入る）、集めた記憶を並べて「What 5 high-level insights can you infer from the above statements? (example format: insight (because of 1, 5, 3))」と問い、**言明を5つ**作らせる。
- **原記録との関係** — 「We parse and store the statement as a reflection in the memory stream, including pointers to the memory objects that were cited.」——**引用元への指しを持ったまま、同じ流れへ足される。** 元の観測は消されない。
- **積み重なり** — 振り返りは振り返り自身も材料にできるため、「agents generate trees of reflections: the leaf nodes of the tree represent the base observations, and the non-leaf nodes represent thoughts that become more abstract and higher-level the higher up the tree they are.」

**計画（planning）。** 一日ぶんを **5〜8 個**の大きな塊にしたうえで、まず1時間ごとへ、さらに **5〜15 分**ごとへと再帰的に割っていく。計画の一件が持つのは「a location, a starting time, and a duration」の三つ。作った計画は記憶の流れへ入る。各時刻で周りを観測し、模型に「今の計画を続けるか、反応するか」を判断させ、反応する場合はその時刻から計画を作り直す。

**評価の設計。** 二日ぶんの模擬を終えた 25 体を対象に、**自己理解・思い出す・計画・反応・振り返り**の5分野それぞれ5問、計25問の面接をした。比べたのは次の5条件で、同じ参加者が全条件を順位づける形（within-subjects）。参加者は 100 人。

| 条件 | TrueSkill の μ（σ） |
|---|---|
| 全部入り | 29.89（0.72） |
| 振り返りなし（観測と計画はある） | 26.88（0.69） |
| 振り返りも計画もなし（観測のみ） | 25.64（0.68） |
| 人が書いた条件（クラウドワーカー） | 22.95（0.69） |
| 観測も振り返りも計画もなし | 21.21（0.70） |

最下段は「the previous state of the art for agents created through large language models」に当たる条件で、全部入りとの差は Cohen の d で 8.16。順位差の全体的な有意性は Kruskal-Wallis 検定（H(4) = 150.29, p < 0.001）。

### 主記憶と外部記憶を出し入れする階層（査読を経ていない）

- Packer C, Wooders S, Lin K, Fang V, Patil SG, Stoica I, Gonzalez JE. "MemGPT: Towards LLMs as Operating Systems." arXiv:[2310.08560](https://arxiv.org/abs/2310.08560) v2, 2024. doi:[10.48550/arXiv.2310.08560](https://doi.org/10.48550/arXiv.2310.08560) — **全文確認。ただし arXiv のプレプリントであり、査読を経ていない。** COLM 2024 の採択論文一覧（2024.colmweb.org/AcceptedPapers.html）を取得して全文検索したが、`MemGPT`・`Operating System`・著者名 `Packer`・`Wooders` のいずれも現れなかった。DBLP にも CoRR（arXiv）の項目しか無い。**「COLM 2024 に採択された」という扱いは、確認した範囲では裏付けが取れない。**

計算機の基本ソフト（OS）が、速い記憶と遅い記憶の間でデータを出し入れして大きな記憶があるように見せる仕組みを、模型が一度に読める窓へ持ち込んだ設計である。

- **主記憶（main context）** — 模型へ実際に渡す部分。三つに分かれる。動かせない**指示文（system instructions）**、大きさが決まっていて模型自身が書き換えられる**作業記憶（working context）**、そして直近のやりとりを並べた**待ち行列（FIFO queue）**。待ち行列の先頭には、追い出された分をまとめた要約が入る。
- **外部記憶（external context）** — 模型からは見えず、呼び出しを経なければ入ってこない部分。長さを問わない文書を置く**書庫（archival storage）**と、全てのやりとりを残す**記録庫（recall storage）**。
- **押し出しの規則** — 「When the prompt tokens exceed the 'warning token count' of the underlying LLM's context window (e.g. 70% of the context window)」で、まず**混んできたという知らせ**を待ち行列へ差し込み、模型自身に大事なものを作業記憶か書庫へ移させる。「When the prompt tokens exceed the 'flush token count' (e.g. 100% of the context window)」で、**窓の 50% 相当を追い出し**、既存の要約と追い出した分から新しい要約を作り直す。追い出された分は「stored indefinitely in recall storage」——**原文は消えない。**
- **続けて呼ぶ仕組み** — 出力に `request_heartbeat=true` を付けると、利用者へ返さずに次の呼び出しへ進める。何段階かに分けて探すのはこれで実現している。

**評価。** Multi-Session Chat を土台に作った **deep memory retrieval（DMR）**で、GPT-4 単体 32.1% に対し MemGPT 付き 92.5%、GPT-4 Turbo 単体 35.3% に対し 93.4%。会話の切り出し（conversation opener）では、人が書いたものの SIM-1 が 0.800 に対し MemGPT+GPT-4 が 0.868。ほかに複数文書の質問応答と、入れ子の鍵と値をたどる課題。

### 失敗を言葉にして次へ持ち越す（査読を経た研究）

- Shinn N, Cassano F, Berman E, Gopinath A, Narasimhan K, Yao S. "Reflexion: Language agents with verbal reinforcement learning." *Advances in Neural Information Processing Systems 36 (NeurIPS 2023)*, 2023. [papers.nips.cc](http://papers.nips.cc/paper_files/paper/2023/hash/1b44b878bb782e6954cd888628510e90-Abstract-Conference.html)（arXiv:[2303.11366](https://arxiv.org/abs/2303.11366)）— **arXiv 版の全文を確認。** DBLP で NeurIPS 2023 の会議論文として確認した。**査読を経た国際会議の論文である。**

行い手（Actor）、採点役（Evaluator）、言語化役（Self-Reflection）の三つを分け、成功・失敗という粗い合図を**言葉による反省文**へ変えて残す。「the trajectory history serves as the short-term memory while outputs from the Self-Reflection model are stored in long-term memory」。長い側は**溜め放題ではなく、覚えておく件数の上限 Ω で区切る**——「we bound mem by a maximum number of stored experiences, Ω (usually set to 1-3) to adhere to max context LLM limitations」。コード生成の実験では上限 1。HumanEval（Python）の pass@1 は GPT-4 の 80.1 に対し 91.0。

### 使えた手順を部品として溜める（査読を経た研究）

- Wang G, Xie Y, Jiang Y, Mandlekar A, Xiao C, Zhu Y, Fan L, Anandkumar A. "Voyager: An Open-Ended Embodied Agent with Large Language Models." *Transactions on Machine Learning Research*, 2024. [openreview.net/forum?id=ehfRiF0R3a](https://openreview.net/forum?id=ehfRiF0R3a)（arXiv:[2305.16291](https://arxiv.org/abs/2305.16291)）— **arXiv 版の全文を確認。** DBLP で TMLR 2024 の学術誌論文として確認した。**査読を経た学術誌の論文である。**

出来事ではなく**やり方**を溜める側の例。「The key is the embedding vector of the program description (generated by GPT-3.5), while the value is the program itself.」——鍵は手順の説明文を数の並びへ写したもの、値は実行できるプログラムそのもの。新しい課題が来たら、解き方の下書きと環境からの返りを問い合わせにして**上位 5 件**を引く。**溜めるのは自己検証を通ったものだけ**で、「repeats the process until a self-verification module confirms the task completion, at which point we commit the program to the skill library」。

### 忘れる速さを数式で置いたもの（査読を経た研究）

- Zhong W, Guo L, Gao Q, Ye H, Wang Y. "MemoryBank: Enhancing Large Language Models with Long-Term Memory." *Proceedings of the AAAI Conference on Artificial Intelligence* 38(17):19724-19731, 2024. doi:[10.1609/aaai.v38i17.29946](https://doi.org/10.1609/aaai.v38i17.29946)（arXiv:[2305.10250](https://arxiv.org/abs/2305.10250)）— **arXiv 版の全文を確認。AAAI の刊行版そのものは未読。** DBLP で AAAI 2024 の会議論文として確認した。**査読を経た国際会議の論文である。**

**溜める側は三層。** ①やりとりを時刻付きでそのまま残す層、②**階層的な出来事の要約**——「We condense verbose dialogues into a concise daily event summary, which is further synthesized into a global summary.」つまり**一日ぶんの要約を作り、それをさらに全体の要約へまとめる**、③**移り変わる人物像**——一日ぶんの性格の見立てを作り、それを全体の見立てへまとめる。②③とも指示文は「Summarize the events and key information in the content [dialog/events]」。

**忘れる側。** エビングハウスの忘却曲線（→ [忘れ方の形](忘れ方の形.md)）から式をそのまま借りている。

> R = e^(−t/S)

R は残っている割合、t は覚えてからの経過時間、S は記憶の強さ。実装は「we model S as a discrete value and initialize it with 1 upon its first mention in a conversation. When a memory item is recalled during conversations, it will persist longer in memory. We increase S by 1 and reset t to 0, hence forget it with a lower probability.」——**S は整数で初めは 1、思い出されるたびに 1 増え、経過時間は 0 に戻る。** 著者自身が直後に「It is important to note that this is an exploratory and highly simplified memory updating model.」と書いている。

**引き出す側**は LangChain と FAISS（近いものを速く探す索引）で、文を数の並びへ写す模型は英語が MiniLM、中国語が Text2vec。

**評価。** ChatGPT に15人ぶんの性格を演じさせて作った10日ぶんの会話を土台に、人手で書いた **194 問**（英語 97・中国語 97）へ答えさせ、引き出せた記憶と応答を人が採点した。

### 記録どうしを結び、古い記録を書き換えるもの（査読を経た研究）

- Xu W, Liang Z, Mei K, Gao H, Tan J, Zhang Y. "A-Mem: Agentic Memory for LLM Agents." *Advances in Neural Information Processing Systems 38 (NeurIPS 2025)*, 2025. [papers.nips.cc](http://papers.nips.cc/paper_files/paper/2025/hash/19909c36f51abc4856b4560aff3d36d6-Abstract-Conference.html)（arXiv:[2502.12110](https://arxiv.org/abs/2502.12110) v11）— **arXiv 版の全文を確認。** DBLP で NeurIPS 2025 の会議論文として確認した。**査読を経た国際会議の論文である。**

一枚のカードに要点と索引語を書いて相互に紐づけていく手控えの方法（Zettelkasten）を下敷きにしている。一件の記憶が持つのは、元の内容、時刻、模型が付けた索引語、札（タグ）、文脈の説明、数の並びへ写した表現、結び先の集合の七つ。新しい記憶が入ると、余弦類似度で近い上位 k 件を出し、模型に結ぶべきかを判断させる。さらに**記憶の育ち（memory evolution）**として、古い記憶の側の文脈の説明・索引語・札を書き換え、「replaces the original memory m_j in the memory set」——**元の記憶を置き換える。**

結ぶ働きと育ちの働きを外した比較（GPT-4o-mini、LoCoMo）は、両方なしの多段推論 F1 が 9.65、結ぶだけで 21.35、両方入りで 27.02。評価データは LoCoMo（Maharana ら, *ACL 2024*, doi:[10.18653/v1/2024.acl-long.747](https://doi.org/10.18653/v1/2024.acl-long.747)。最大 35 回ぶん・平均 9K トークンの対話、計 7,512 問）と DialSim（テレビ番組から作った 1,300 回ぶんの多人数対話）。

**時間による減衰も重要度の数値も置いていない。** 本文に `decay`・`recency`・`forget` の語は一度も現れず、時刻は属性として持つだけである。

### 事実に効く期間を持たせるもの（査読を経ていない／作った会社自身による）

- Rasmussen P, Paliychuk P, Beauvais T, Ryan J, Chalef D（いずれも Zep AI 所属）. "Zep: A Temporal Knowledge Graph Architecture for Agent Memory." arXiv:[2501.13956](https://arxiv.org/abs/2501.13956) v1, 2025. doi:[10.48550/arXiv.2501.13956](https://doi.org/10.48550/arXiv.2501.13956) — **全文確認。arXiv のプレプリントであり、査読を経ていない。また、著者は全員が同名の製品を売る会社の所属である。**

記憶を三層のつながり図（知識グラフ）で持つ。①**出来事の層**——「Episodic nodes (episodes) ... contain raw input data in the form of messages, text, or JSON」、②**意味の層**——出来事から取り出して既存のものと突き合わせた実体、③**まとまりの層**——強く結ばれた実体の集まり。

**二本の時間軸（bi-temporal）**を持ち、辺に四つの時刻を置く。t_valid と t_invalid が**その事実が実際に成り立っていた期間**、t'_created と t'_expired が**その事実を取り込んだ・打ち消した順序**。矛盾を見つけたとき、古い辺の t_invalid に新しい辺の t_valid を入れることで無効にする。引き出す側は、余弦類似度・BM25（語の重なりで探す古典的な方法）・幅優先の辿りの三つを並べ、RRF や MMR で並べ直す。

**評価。** MemGPT が作った DMR で 94.8%（MemGPT は 93.4%）。LongMemEval では gpt-4o の全文投入 60.2% に対し 71.2%、渡す文の量は 115k から 1.6k、応答時間は 28.9 秒から 2.58 秒。

**減衰も重要度も置いていない。** 本文に `decay`・`recency`・`importance`・`forget` の語は一度も現れない。時間は減衰の係数ではなく、**事実が効いていた期間の端点**として持たれている。

### 思い出す質を測る側（査読を経た研究）

- Wu D, Wang H, Yu W, Zhang Y, Chang KW, Yu D. "LongMemEval: Benchmarking Chat Assistants on Long-Term Interactive Memory." *ICLR 2025*. [openreview.net/forum?id=pZiyCaVuti](https://openreview.net/forum?id=pZiyCaVuti)（arXiv:[2410.10813](https://arxiv.org/abs/2410.10813)）— **要旨のみ確認。本文は未読。** DBLP で ICLR 2025 の会議論文として確認した。**査読を経た国際会議の論文である。** 情報の取り出し・複数回にまたがる推論・時間の推論・知識の更新・答えを差し控えること、の5つの力を 500 問で測る。要旨は「commercial chat assistants and long-context LLMs showing a 30% accuracy drop on memorizing information across sustained interactions」と述べている。

## 限界

- **査読の有無が割れている。** 査読を経ているのは Generative Agents（UIST 2023）、Reflexion（NeurIPS 2023）、Voyager（TMLR 2024）、MemoryBank（AAAI 2024）、A-MEM（NeurIPS 2025）、LongMemEval（ICLR 2025）。**MemGPT と Zep は arXiv のプレプリントのままである。** 特に MemGPT は引用されることが多いが、COLM 2024 の採択一覧を取得して調べた範囲では採択の裏付けが無い。

- **Generative Agents の数値は「一つの実装の設定」であって、測って選ばれたものではない。** 減衰の係数 0.995、振り返りの起動の閾値 150、直近 100 件、問い3つ、言明5つ、重み α が全て 1 ——本文はいずれも「in our implementation」と書くだけで、**なぜその値かも、他の値と比べた結果も書かれていない。** 比較実験は「観測／計画／振り返りを使うか使わないか」であって、**重みや係数を動かした比較は行われていない。** 著者自身も今後の課題として「the retrieval module ... could be enhanced ... by fine-tuning the relevance, recency, and importance functions」と書いている。

- **測っているのは「もっともらしさ（believability）」の順位であって、思い出した内容が正しいかではない。** 著者自身が失敗を列挙している。**取り違え**——選挙について聞かれた人物が「I haven't been following the election too closely」と答えたが、実際には候補者の話を聞いていた。**断片だけの想起**——催しの記憶は出てこないのに、そこで話す予定の内容だけが出てきた。**作り足し**——「They did not affirmatively claim to have experienced something they had not. Nonetheless, they still exhibited instances of hallucination where they embellished their knowledge.」

- **記録が増えるほど振る舞いが崩れる、と著者自身が書いている。** 「synthesizing an increasingly larger set of memory not only posed a challenge in retrieving the most relevant pieces of information but also in determining the appropriate space to execute an action」——溜まるほど、選ぶのも、どこで振る舞うかを決めるのも難しくなる。**この論文が測ったのは模擬世界の二日ぶんで、著者は「a relatively short timescale」に限られると明記している。** 25 体を二日動かすのに「thousands of dollars in token credits」と数日を要した、とも書いている。

- **同調しすぎる傾向が観測されている。** 「the instruction tuning also seemed to make the agents overly cooperative with one another ... Despite these ideas not aligning with her own interests and characteristics, she rarely said no. Over time, the interests of others shaped her own interests」。**気持ちや性格の一貫性を扱う設計にはそのまま効く観測だが、著者は原因を仕組みではなく模型側の調整（instruction tuning）に帰しており、対処は検証されていない。**

- **「振り返り」は、確認した範囲では「選んで捨てる」ではない。**
  - Generative Agents — 起動は**日の区切りではなく重要度の合計が閾値を超えたとき**（結果として一日に2〜3回）。作られるのは**元の記録を残したまま同じ流れへ足される別の記憶**で、引用元への指しを持つ。**原記録の削除も、日ごとの取捨も行わない。**
  - MemoryBank — こちらは**日の区切りで要約を作る**（daily event summary → global summary）。ただし**要約は原記録の代わりではなく別に持たれ**、原記録を減らすのは忘却曲線の側が別途担う。
  - A-MEM — 新しい記憶が入ると**古い記憶の属性を書き換えて置き換える**。層を足すのではなく、既存を上書きする側である。
  - MemGPT — 窓から追い出すときに要約を作り直すが、追い出した原文は記録庫へ「indefinitely」残す。
  - **つまり「一日ぶんの記憶から残すものを選び、要点の層を作る」に最も近いのは MemoryBank の日次要約であり、Generative Agents の振り返りは日を区切らず、選別もしない。**

- **MemoryBank の忘却の仕組みは、効くかどうかが測られていない。** 本文に `ablation` の語は一度も現れず、**忘却の有無で比べた結果が無い。** 「Applicability with and without memory forgetting mechanism」と特長には挙げるが、比較は載っていない。
- **MemoryBank は要旨と本文が食い違っている。** 要旨は「based on time elapsed and the relative significance of the memory」と書くが、**式に現れるのは経過時間 t と呼び出し回数 S だけで、重要度に当たる数値は本文のどこにも定義されていない。**
- **MemoryBank の評価データは模型が作ったものである。** 会話は ChatGPT に15人ぶんの性格を演じさせて生成した。実在の利用者を10日追った記録ではない。
- **MemoryBank が借りた式は、人の忘却の研究では当てはまりが最も悪い側の形である。** R = e^(−t/S) は単一の指数式である。→ [忘れ方の形](忘れ方の形.md) にあるとおり、210のデータ集合を集めた比較では単純な指数式は一貫して下位に来ており、エビングハウス本人のデータでも冪や対数に大きく劣る。**人の忘却をまねたと述べる一方で、借りた式は人の忘却の記述としては支持されていない、という食い違いがある。** ただし MemoryBank 自身はこの点に触れておらず、著者は「exploratory and highly simplified」とだけ書いている。
- **「いつ・何回使われたかから思い出しやすさを一つの数にする」設計には、人の記憶研究の側に別系統の蓄積がある。** → [思い出しやすさを数で置くこと](思い出しやすさを数で置くこと.md)。ここで挙げた実装のうち、その系統に触れているのは Generative Agents が関連研究で Anderson JR *Rules of the Mind*（Lawrence Erlbaum, 1993）を、記号を扱う古い設計（SOAR・ICARUS）の出どころとして一度挙げているだけである。**新しさの係数 0.995 を選ぶにあたって、その蓄積を参照した形跡は本文に無い。**

- **Zep は自社製品の文脈で出された事例研究である。** 著者は全員が Zep AI 所属で、比較対象の MemGPT より良い数値（94.8% 対 93.4%）を出しているが、**同じ節で著者自身が「each conversation contains only 60 messages, easily fitting within current LLM context windows」「Our analysis revealed significant weaknesses in the benchmark's design」と、その評価法の弱さを述べている。** また gpt-4o の single-session-assistant は 17.7% 下がっている。

- **MemGPT には限界の節が無い。** 本文中に散らばる形で、「MemGPT will often stop paging through retriever results before exhausting the retriever database」（探し尽くす前に打ち切る）と、「MemGPT has significantly degraded performance using GPT-3.5, due to its limited function calling capabilities」（下位の模型では大きく劣化する）が述べられているだけである。**土台の模型が道具を呼ぶ力に強く依存している。**

- **Reflexion と Voyager は、出来事の記憶ではない。** Reflexion が残すのは**失敗の反省文**で、しかも上限 Ω は 1〜3 件、押し出し方式である。著者自身が限界の節で「we limit long-term memory to a sliding window with maximum capacity」と書き、より進んだ構造への拡張を今後の課題としている。Voyager が残すのは**実行できる手順**で、自己検証を通ったものだけである。**どちらも「誰といつ何があったか」を思い出す設計ではない。**

- **同じ「reflection」という語が別のものを指している。** Generative Agents では**観測から高次の言明を作ること**、Reflexion では**失敗した試行を言語化すること**。名前が重なっているだけで、起動の条件も、作られるものも、残り方も違う。

- **評価の土台そのものが疑われている。** LongMemEval（ICLR 2025）の要旨は、市販の対話補助と長い窓を持つ模型が、やりとりが続くと 30% 精度を落とすと述べている。**MemGPT が作った DMR は、後から Zep 自身によって「単発・事実照会だけで複雑な記憶の理解を測れていない」と批判されている。** 何をもって「思い出せている」とするかは、この分野でまだ定まっていない。

- 確度の整理。**査読を経た研究**——Generative Agents（UIST 2023）、Reflexion（NeurIPS 2023）、Voyager（TMLR 2024）、MemoryBank（AAAI 2024）、A-MEM（NeurIPS 2025）、LongMemEval（ICLR 2025）。**査読を経ていないプレプリント**——MemGPT、Zep。**事例研究（販売者が自社製品の文脈で出したもの）**——Zep。**いずれも人工の系の設計と評価であり、人の記憶の理論としての階層には属さない。**
