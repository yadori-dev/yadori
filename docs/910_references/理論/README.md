# 理論資料

設計や要求を疑うときに、一次情報へ戻るための索引である。

各文書には「何をするものか」「一次情報」「限界」だけを書く。yadori で採る方法は [進め方](../../000_process.md)、[要求分析](../../110_requirements/)、[決定記録](../../010_decisions/) に書き、ここへ適用判断や調査の経緯を重ねない。理論を要求や受入基準へ持ち込むときは、学者役が一次情報で確かめてから、当てはめた箇所を推論と明記する（進め方 3 節）。

## 探し方

- 眠りと記憶: 眠っている間に記憶が固まる・整理される・薄れる・繋がる仕組み、夢の内容と記憶の関係、夢の機能をめぐる学説
- 思い出す: 意味の近さで探すこと、思い出しやすさが使うほど上がり放っておくと下がること
- 気持ちと性格: 出来事で動き時間で薄れること、長い時間をかけて傾向が変わること

題名は結論ではなく、調べた問いを表す。限界まで読んでから使う。
