# 現在のシステム

ここには、現在のコードと一緒に変わる説明だけを置く。過去の姿や変更の経緯は書かない。

- [`全体構造.md`](全体構造.md): 外との境界、層と機能、依存の向き
- [`用語集.md`](用語集.md): 利用者が使う言葉とコードの名前

コードの構造や言葉を変えた場合は、同じ PR で該当する文書を直す。現在の進み具合は Issues、変更して確認した結果は PR を見る。

## 書き方

- 現在の事実だけを書く。変更前との比較やレビュー履歴を足さない
- 同じ事実がコードにある場合は、写さず正典へリンクする
- 図は構造や順序が文章より分かりやすい場合だけ使う。差分と機密検査が働くテキスト形式で書く
- なぜその形を選んだかが将来必要なら ADR に分ける
