# 用語集

利用者が使う言葉と、コードで使う名前の対応である。**ここに無い概念へ勝手に名前を付けない。** 新しい概念が要るときは、先にこの表へ足す。

コードの名前は、保存先や仕組みではなく、宿りに起きることで付ける。「感情を注入する」は仕組みの言葉であり、使わない。

## 宿りと持ち主

| 利用者が使う言葉 | コードの名前 | 意味 |
|---|---|---|
| 宿り | `dweller` | 名前を持つ一人ぶんの存在。記憶、気持ち、性格、気がかり、夢はすべてどれか一つの宿りに属する。保存の形の最上位（[ADR-014](../010_decisions/ADR-014-宿りを名前を持つ最上位の存在とし記憶と状態をそこへ結ぶ.md)） |
| 名前 | `name` | 宿りを見分け、話しかける相手を選ぶために使う。例: 田中れいな |
| 呼び名 | `nickname` | 普段そう呼ぶ短い名。例: れいな |
| 持ち主 | `owner` | その宿りが誰のものか。一人の持ち主が複数の宿りを持てる |
| 話す人 | — | 宿りに話しかける人。多くの場合は持ち主と同じ |
| 常駐 | — | 宿りたちが動いている場所。業務の概念ではなく、動かし方の話である |
| 出ていく先 | `place` | Discord、Claude Code など、宿りが話す場所 |

一つの常駐が複数の宿りを同時に扱う。持ち主が同じでも違っても混ざらない。宿りが一つしかない間もこの階層を省かない。

## 記憶

記憶は種類ごとに別の仕組みではなく、薄れる速さが違う一つの仕組みである（[ADR-005](../010_decisions/ADR-005-記憶を減衰の速さが違う一つの仕組みとして持つ.md)）。

| 利用者が使う言葉 | コードの名前 | 薄れる速さ | 意味 |
|---|---|---|---|
| 出来事の記憶 | `episode` | 原文は薄れない | 一度のやりとりを原文のまま保存したもの。消さない（[ADR-006](../010_decisions/ADR-006-会話の原文を正典とし埋め込みを作り直せる索引とする.md)） |
| 気持ち | `mood` | 分から時間 | 一度のやりとりで動き、時間とともに元へ戻る |
| 気がかり | `concern` | 日から週 | 言いたいこと。解決すると消え、繰り返すと太る（[ADR-009](../010_decisions/ADR-009-気がかりを予定ではなく減衰する記憶として持つ.md)） |
| 性格 | `character` | 月から年 | 積み重なった出来事によって変わる応対の傾向 |

この表が扱うのは、**経験から積まれるもの**だけである。持ち主が書いて与える名乗りは別に持つ。

## 名乗り

| 利用者が使う言葉 | コードの名前 | 意味 |
|---|---|---|
| 名乗り | `identity` | 宿りが誰であるか。名前、自分の呼び方、話し方、自分について変わってほしくない事柄。持ち主が書いた一続きの文章として持ち、項目に割らない（[ADR-013](../010_decisions/ADR-013-名乗りは積まず書いたものを版で持つ.md)） |
| 名乗りの版 | `identity_version` | 書き直すたびに増える。以前の版は消さず、どの応対がどの版で作られたかを読める |

**名乗りは書かれるもの、性格は積まれるもの。** 同じ「その人らしさ」でも出所が違う。会話で変わってほしい部分は性格へ、何があっても変わってほしくない部分は名乗りへ書く。

## 記憶に対してすること

| 利用者が使う言葉 | コードの名前 | 意味 |
|---|---|---|
| 思い出す | `recall` | 話しかけられた文章から、関係する記憶と今の状態を取り出す |
| 思い出したこと | `recollection` | `recall` が返すもの。直近のやりとりと、探した記憶と、名乗りと、今の状態 |
| 直近のやりとり | `recent` | 意味を見ずに常に渡す新しい順のやりとり。「それ」「あれ」のように指す語だけの発話は意味で探しても出ないため、別の道で渡す |
| 探した記憶 | `found` | 直近より前から、意味の近さで選んだ記憶。同じ語を使っていなくても出る |
| 道 | `way` | 探した記憶を出す一つの経路。埋め込みごとに一本あり、探した記憶はどの道で出たかを持つ。道ごとの点数は混ぜない |
| 覚える | `remember` | 一度のやりとりを記憶へ加え、状態を動かす |
| 一往復 | `Turn` | 話しかけられてから覚えるまで。宿り自身が話す場所で使う。対話する道具では使わず、思い出すと覚えるを別の時点で呼ぶ |
| 声 | `Voice` | 名乗りと思い出したことから応対の文章を作るもの。宿り自身が話す場所でだけ使う |
| 応対 | `Response` | 一往復の結果。応対の文章と、何を思い出して作ったかを持つ |
| 近さ | `relevance` | ある記憶が、その発話にどれくらい関係あるか。意味だけで決まる |
| 思い出しやすさ | `retrievability` | ある記憶がどれだけ出てきやすいか。思い出すたびに強まり、放っておくと下がる。近さとは別の値として持ち、同じ点数へ混ぜない（[ADR-015](../010_decisions/ADR-015-思い出しやすさを思い出された記録から求め並べ替えの点数に混ぜない.md)） |
| 思い出した記録 | `retrieval` | いつどの記憶を思い出したか。思い出しやすさはここから求める。直近で渡したものは数えない |
| 索引 | `index` | 意味で探すために原文から作った派生物。捨てて作り直せる |
| 動き | `shift` | 気持ちや性格が、いつ何によってどちらへどれだけ動いたかの記録。現在値はここから求める（[ADR-007](../010_decisions/ADR-007-気持ちと性格を上書きせず出来事から求める.md)） |

## 話しかけられていない間

| 利用者が使う言葉 | コードの名前 | 意味 |
|---|---|---|
| 夢 | `dream` | 話しかけられていない間に記憶を読み直し、まとめ直し、気づくこと。一回ごとに記録が残る |
| 気づき | — | 夢の中で生まれる。結果は `concern` になる |
| 話しかける | `speak_up` | 宿りの側から口を開くこと |
| 頃合い | `occasion` | 気がかりが言われたい状況。時刻ではない |
| 確かめ | `check` | 話す前に、その気がかりがまだ言う価値があるかを確かめること。ここで取りやめになることがある |
| 理由 | `reason` | なぜそのとき話しかけたかの記録（[ADR-011](../010_decisions/ADR-011-口を開くかの判定に模型を使わない.md)） |

## 測る

| 利用者が使う言葉 | コードの名前 | 意味 |
|---|---|---|
| 評価セット | `recall_eval` | 覚えさせる会話と、測る件の集まり。思い出す質の判定に使う。リポジトリに置くものは架空の会話で作り、実際の会話から作ったものは手元に置く（[ADR-010](../010_decisions/ADR-010-思い出す質を評価セットで判定する.md)） |
| 件 | `case` | 一つの発話と、そのとき出るべき記憶・出てはいけない記憶。名前を持ち、差の中で名指しできる |
| 結果 | `outcome` | 一件を測った結果。期待した記憶の順位と、出てはいけない記憶の近さを持つ |
| 測定 | `measurement` | 全件の結果。要約はここから求め、別に持たない |
| 差 | `difference` | 二つの測定の間で、良くなった件と悪くなった件。変わらなかった件は入れない |
| 記録 | `record` | 対話する道具（Claude Code、Codex）が手元に残した会話の記録。宿りの記憶ではなく、評価セットの材料として読む |
| 記録の一往復 | `recorded` | 記録から取り出した、発話、返事、時刻、作業場所、セッションを持つ一組。中身があるかを自分で答える。話しかけられてから覚えるまでの一往復（`Turn`）とも、評価セットのやりとり（`exchange`）とも別 |
| 作業場所 | `workspace` | 記録が残されたときに動いていたディレクトリ。同じ作業場所の中で話題が戻ることが多いため、組を探す範囲にする。出ていく先（`place`）とは別 |
| 組 | `pair` | 判定が返す、後の発話と、それが指す前の発話の一対。同じ後の発話の組は、期待を複数持つ一件にまとまる |
| 下書き | `draft` | 記録から作った、人がまだ確かめていない評価セット。件ごとに確認前の印を持つ |
| 確認済み | `confirmed` | 下書きの件を人が読み、期待が妥当だと決めた印。確認前の件が残る評価セットは測れない |
| 候補 | `candidate` | 後の発話ごとに、探した記憶（`found`）と同じ仕組みで下書きのために広めに引いた前の発話。判定に渡すのはこれだけ |
| セッション | `session` | 対話する道具を起こしてから終えるまでの一続きの記録。記録の一往復がどのセッションのものかを持つ |
| 判定 | `judge` | 後の発話と候補を受け取り、候補のうちどれが同じ話題かを答えること。対話する道具が担う（[ADR-017](../010_decisions/ADR-017-実際の会話の記録を判定のために対話する道具へ渡す.md)） |
| 読めない記録 | `BrokenRecord` | 形式は合っているが途中で読めない記録のファイル。そのファイルだけを飛ばして数える |
| 道具の失敗 | `ToolCallFailed` | 対話する道具を呼べなかった、または返事を読めなかった。大きすぎ（`TooLongForTool`）と上限（`ToolLimitReached`）は種類を分け、呼ぶ側が自分の失敗へ言い換える |
| 下書きの失敗 | `CannotDraft` | 下書きを作れない理由。記録が読めない、判定が続かない、出力先が境界の外にある。何も書かずに返す |
| 語の重なりの度合い | `overlap` | 件と期待の発話が文字の並びをどれだけ共有するか。小さいほど言い換えの件である。件に期待ごとの値として書く。人が件を選ぶ手掛かりであり、判定にも測る側にも使わない |

## 使わない言葉

| 使わない | 理由 | 代わりに |
|---|---|---|
| 注入する / inject | プロンプトに対して何をするかという仕組みの言葉。宿りに何が起きるかを表していない | `recall` |
| 予定 / schedule | 必ず発火することを含意する。気がかりは薄れて消える | `concern` |
| 感情 | 短く薄れるものと、長く続く傾向が混ざる | `mood` と `character` に分ける |
| プロフィール | 何が入るのか読み手に伝わらない。積まれるものと書かれるものの区別も付かない | `identity`（名乗り） |
| 人格設定 / キャラ設定 | 設定という語が、動かせる項目の集まりを連想させる。名乗りは項目ではなく文章である | `identity`（名乗り） |
