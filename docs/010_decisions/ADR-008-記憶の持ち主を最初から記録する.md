# ADR-008 記憶の持ち主を最初から記録する

| 項目 | 内容 |
|---|---|
| 状態 | 有効 |
| 決定日 | 2026-08-31 |

## 判断

すべての記憶、状態、気がかり、夢に、**誰の宿りのものか**を最初から持たせる。保存の形にも、内側の口の引数にも入れる。利用者が一人しかいない間も同じである。

## 理由

この道具は、他人がそれぞれの宿りを持てるものとして作る。一つの常駐で複数の宿りを扱うとき、持ち主が無いと記憶が混ざる。混ざった記憶は、混ざったことに気づいた時点で分離できない。

後から持ち主を足すのは、すべての保存済みデータに対する移行になる。逆に、使われない列が一つ多いだけなら費用はほとんど無い。**戻す費用が釣り合わない**ため、先に払う。

これは将来のための投機的な作り込みではない。他人も使えるようにすることは既に決まった要求である。

## 受け入れる不利益

利用者が一人の間、この値は常に同じ値になり、意味を持たない列とテストが増える。

## 見直す条件

見直さない。持ち主を持たない設計へ戻す判断は、記憶の混在を許すことと同じである。
