# 原文に根拠付きの補完を結び索引を再構築する

## 判断

原文を変えず、会話の所属と直接の先行往復の出典を添える。補完は対象と規則の版で一意な別の記録にし、説明、応答種別、理由、生成時刻、根拠を持つ。説明と検索用の数値表現を同じ取引で確定する。索引の再構築の入力は原文と確定した補完であり、文章生成は不要である。AC-009 の原文保存の要求を維持し、再構築はこの二つの保存済み記録を入力にする。

## 状況と選択肢

短い承認は原文だけでは対象を検索できない。原文の置換は発言を失い、要約の変更だけでは過去の記憶へ届かない。説明を索引の中だけに置くと索引を消した際に再生成が要るため、原文・補完の記録と使い捨ての索引を分離する。

## 不利益と見直す条件

原文だけを保管する場合より保存項目が増える。所属と直接の先行往復を確認できない既存の記憶は保留になる。先行文脈は出典の連鎖で最大3往復とし、長さを超えた場合は条件を切り落とさず保留にする。補完の検索精度が固定評価で改善しない場合は採用を見直す。
