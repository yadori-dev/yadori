# ADR-021 出来事へ思い出した時刻と出典を足し、以前の記憶は不明のまま残す

| 項目 | 内容 |
|---|---|
| 状態 | 有効 |
| 決定日 | 2026-09-07 |

## 判断

出来事の記憶へ、返事を作る前に思い出した時刻 `recalled_at` と、一回の往復を一意に指す出典 `source` を足す。どちらも以前の記憶では値が無いため、不明を表せる形にする。新しく二つの入口を通った往復は思い出した時刻を持ち、複数の処理へ分かれる入口は出典も持つ。

出典を持つ出来事は、その出典を一人ぶんの宿りで一件に限る。同じ出典が再び届き、発話、返事、名乗りの版、思い出した時刻と、気持ちの動きの大きさ・理由が同じなら既存の出来事を返す。気持ちの印を外した返事本文が同じでも、動きが違えば同じ往復とは扱わない。いずれかが違えば、黙って上書きせず不整合として断る。

出来事の原文と、その一往復で起きた気持ちの動きは、一つの保存処理でまとめて確定する。どちらかを保存できなければ両方を取り消し、原文だけ、または気持ちだけの半端な往復を残さない。同じ出典を再び受け取ったときも、この処理の中で既存の値との一致を確かめる。

検索用の索引は、原文と気持ちの確定後に書く。索引だけを保存できない場合は原文と気持ちを残し、フックの再送や次回起動時に、欠けた索引を原文から補う。索引は原文から作り直せる派生物として扱う `ADR-006` の判断を保つ。

以前の保存先を開いたときは、一つの処理の中で二つの列と、値がある出典だけを一意にする索引を足す。以前の発話、返事、名乗りの版、発生時刻は変えず、思い出した時刻と出典は不明のままにする。途中で失敗した場合は変更を取り消し、以前の保存先をそのまま残して起動を断る。

## 必要になった状況

Claude Code の正式なフックは、返事の前と思い出した後を別の処理で呼ぶ。同じフックが再送されても一往復と気持ちの動きを一件に保つには、保存先が出典を見て確定する必要がある。また、思い出してから返事が終わるまでに別の入口で気持ちが動きうるため、どの状態を返事へ渡したかは発生時刻だけでは求め直せない。

## 検討した候補

- 以前の記憶の思い出した時刻を発生時刻で埋める: 実際には分からない時刻を確定した値にするため採らない
- フックの未完ファイルだけで再送を防ぐ: 終了後の再送や並行した処理では一件を保証できないため採らない
- 出典を別の表へ置く: 出来事と必ず一対一で変わり、読み書きが二箇所になるため採らない
- 出来事へ不明を許す二項目を足す: **採る。** 以前の原文を変えず、新しい往復だけを正確に追える

## 理由

不明な過去を不明のまま残せば、確認できていない時刻を事実として扱わずに済む。出典の一意性を保存先で守り、原文と同じ出来事へ積む気持ちを一つの取引で確定すれば、処理が中断した場所や並行実行にかかわらず、半端な往復を残さず、同じ往復を二重に積まず、異なる動きを黙って捨てない。索引をこの取引へ含めないことで、復元可能な派生物の失敗が正典の確定を巻き戻すことも防ぐ。これらは出来事そのものの性質なので、未完ファイルや Claude Code のアダプタではなく正典の保存先へ置く。

## 受け入れる不利益

以前の出来事は、返事を作る前の状態を正確には求め直せない。出来事を読む側は、思い出した時刻と出典が不明な場合を扱う必要がある。保存先を初めて開くときに形を変える処理が走り、その処理に失敗すると新しい版では起動できない。

## 見直す条件

出来事を保存する前後が一つの処理に閉じ、出典による再送対策が不要になったとき。以前の思い出した時刻を事実に基づいて復元できる記録が見つかったとき。
