# ADR-017 実際の会話の記録を、判定のために対話する道具へ渡す

| 項目 | 内容 |
|---|---|
| 状態 | 有効 |
| 決定日 | 2026-08-31 |

## 判断

評価セットの下書きを作るとき、**持ち主の実際の会話の記録を、後の発話が前のどの話題を指すかの判定のために、手元の対話する道具（Claude Code）へ渡す**。渡すのは発話の文章だけで、返事、時刻、作業場所は渡さない。道具の文脈は外して呼ぶ（[ADR-016](ADR-016-応対は対話する道具を通して作り、その道具の文脈を持ち込まない.md) と同じ呼び方）。

どの記録を渡すかは、持ち主が置き場を指すことで選ぶ。使い方に、どの記録がどの相手へ渡るかを書き、実行する前に読める。

## 必要になった状況

思い出す質は実際の会話から作った評価セットで測る（[ADR-010](ADR-010-思い出す質を評価セットで判定する.md)）が、その評価セットは人が記録を読んで一件ずつ書き写しており、数十件が限度だった。後の発話が前のどの話題を指すかを機械に候補として出させる必要があり、その判定には文章の意味を読む何かが要る。

## 選択肢

1. 人が全部読む。続かない
2. 測られる側の埋め込みで近い組を候補にする。埋め込みが見つけられない組こそ測りたいのに、それが評価セットから消える
3. 対話する道具に判定させる。測られる側とは別の仕組みで、定額契約の範囲で動く。**採る**
4. 別の提供元の模型へ鍵で繋いで判定させる。従量課金になり、渡る相手も増える

## 理由

3 は、測る側と測られる側を別の仕組みにでき、鍵も課金も増やさない。Claude Code の記録については、その会話が普段通っている相手と同じ相手へ渡るため、新しい経路が生まれない。

## 受け入れる不利益

**Codex の記録は、今まで渡っていなかった相手へ渡る。** 渡してしまった後では戻せない。持ち主が置き場を指して選ぶ形にし、使い方に書いて事前に読めるようにするが、渡すこと自体は避けない。

判定に定額契約の上限を消費する。上限に当たると宿りの応対まで使えなくなる。上限に当たれば下書きを書かずに断る。

## 見直す条件

手元で動く模型で判定の質が足りると測って確かめられたとき（外へ渡さずに済む）。または、判定のために渡した会話が意図しない用途へ使われることが分かったとき。
