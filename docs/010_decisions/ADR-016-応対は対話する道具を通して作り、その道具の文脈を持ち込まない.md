# ADR-016 応対は対話する道具を通して作り、その道具の文脈を持ち込まない

| 項目 | 内容 |
|---|---|
| 状態 | 有効 |
| 決定日 | 2026-08-31 |

## 判断

宿りの応対の文章は、AIモデルの提供元へ直接つなぐのではなく、**手元の対話する道具（Claude Code）を通して**作る。持ち主の定額契約で動かすためである。従量課金の鍵は設定しない。

宿りの本体が応対の文章だけを作るために呼ぶときは、**その道具が普段持ち込む文脈を必ず外す**。具体的には、道具そのものの指示、持ち主が手元に置いた指示、道具が使う仕組みを外し、道具を持たせない。

その呼び方では、**AIモデルの側のやりとりを続けない。** 一往復ごとに新しく呼ぶ。

利用者が Claude Code を操作する場所として使うときは例外とする。作業の手順と道具の結果を会話中だけ保つことが、対話型の道具として使うために必要だからである。ただし、その履歴は起動中の一時的な文脈とし、終了後は捨てる。過去の会話は再開せず、宿りが持つ一往復の記憶だけを正とする。持ち主の指示と Claude Code 自身の自動記憶は外すが、作業に必要な道具は持たせる。

## 理由

**持ち込むと、名乗りのとおりに応対しなくなる。** 対話する道具は、それ自身の役割の指示と、持ち主が手元に置いた指示を前置きとして渡す。宿りの名乗りはその後ろに置かれるため、前置きのほうが強く出る。実際に、名乗りへ書いていない話し方が応対に現れた。これは `SPEC-006-001` を満たさない。

**前置きの量も違う。** 外さずに呼ぶと前置きは約六万語だったが、外すと三百語ほどになった。宿りが受け取る文脈のほとんどが、宿りと関係のない指示だったことになる。

**AIモデルの側のやりとりを続けない理由は、記憶が二つになるからである。** 道具の側にもやりとりが積まれるため、続けると、こちらが持つ記憶と道具が持つ文脈という二つの記憶ができる。二つは同じようには薄れず、片方だけを整理でき、食い違ったときにどちらが本当かを決められない。記憶はこちらが持つ（[ADR-006](ADR-006-会話の原文を正典とし埋め込みを作り直せるインデックスとする.md)）。

対話中の一時的な文脈まで禁じると、同じ作業の続きを話すたびに、実行した手順や結果を渡し直すことになる。終了時に捨てれば、作業中の文脈を利用しつつ、長く残る記憶が二つになることは避けられる。

## 受け入れる不利益

定額契約の利用上限にかかる。応対のたびに手元の別のプログラムを起こすため、直接つなぐより遅い。道具の呼び出し方が変わると、こちらも直す必要がある。対話型の場所は過去の会話を再開できないため、後で必要な作業の結果は別の適切な場所へ残す必要がある。

## 見直す条件

定額契約の上限が普段の会話で問題になったとき、または、外すべき文脈を外せない形へ道具が変わったとき。応対を作る相手は口として受け取っているため（`AD-006-001`）、直接つなぐ実装へ差し替えられる。
