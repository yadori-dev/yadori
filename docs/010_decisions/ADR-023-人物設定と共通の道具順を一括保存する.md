# ADR-023 人物設定と共通の道具順を一括保存する

## 判断

`YADORI_HOME/settings.toml` を対話設定の保存先とする。`version = 1`、`active`（人物の id）、`priority`（道具名の配列）、`[models]`（任意の道具別の内部呼出モデル）、`[people."人物id"]`（名前・呼び名・持ち主・id・identity と既存の追加設定）を持つ。道具順は人物の外へ置く。

保存前に全内容を組み立てて検証し、一時ファイルを同期してから一度の置換で公開する。編集中に元ファイルが変わった場合は保存しない。ファイルの破損・読取不能は設定無しとして扱わない。未知の版は変更せず断る。

旧 dweller.toml と identity.md は新ファイルが無い間だけ読む。移行時も原本を削除しない。id が無い人物は旧 nickname を id に固定し、以後の呼び名変更で記憶の帰属を変えない。memories.sqlite の保存形式、人物ごとの原文・状態・名乗りの版は変えない。

## 背景と選択肢

複数ファイルを順番に上書きすると初回設定の中断で一部だけ変わる。単一の確認・置換により人物と順序を一括で確定できる。記憶を人物別のディレクトリへ移す案は、既存の人物 id による分離と重複し原文移行の危険を増やすため採用しない。

## 不利益と見直す条件

移行後は旧ファイルへの手編集は反映しない。README と設定画面で現在の正典を示す。人物数が手動の表追加で扱えない規模になった場合は、人物追加画面を別要求で検討する。
