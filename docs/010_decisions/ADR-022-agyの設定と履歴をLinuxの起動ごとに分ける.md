# ADR-022 agy の通常起動と内部呼び出しを分ける

## 判断

利用者が操作する `yadori agy` は、普段の agy に追加ディレクトリを渡す。その `.agents` に宿りの PreInvocation と Stop のフック、および記憶の MCP を置く。設定・認証・権限・履歴・技能・プラグインの探索は agy 自身が行う。起動と再開の共通境界は [ADR-020](ADR-020-Claude-Codeの会話履歴を宿り専用に分け手元の設定は参照して使う.md) に従う。

内部の要約・判定は、通常の文脈を混ぜない目的のため、Linux の bubblewrap で設定と履歴を分ける。この内部呼び出しには導入済みの対応版と既存の認証が必要で、利用者の対話起動とは別の経路である。

## 記憶と失敗時

PreInvocation で名乗りと記憶を渡し、正常な Stop で完成した一往復を保存する。通常の履歴の根を起動時に固定し、その配下の会話IDと発話番号から原文を読む。回復用の状態は宿りの一時領域へ会話別に分ける。

agy はフックの非ゼロ終了だけではモデル呼び出しを止めない。そのため宿りの通知処理に期限を置き、失敗時は当該 agy を止める。普段のフックや権限設定は無効化しない。

完成した返事は保存前に回復記録へ残し、同じ出典の再送で二重保存を防ぐ。正常終了でも未保存記録は残す。次回は施錠されていない記録を回復し、完成状態を確かめられない記録を捨てない。

## 選択肢と不利益

通常設定を書き換えて元に戻す方法は、同時起動と異常終了で混入するため採用しない。設定と履歴を対話起動ごと分ける方法は、普段の道具や再開を使えなくするため対話起動には使わない。

追加ディレクトリが agy の作業場所として見える。フックと履歴形式は実際の道具で照合し、変更を追う必要がある。

根拠: [フックの仕様](https://antigravity.google/docs/hooks/)、実 agy の `--help` と追加ディレクトリからのフック実行。検証の詳細は Issue #102 と PR に置く。
