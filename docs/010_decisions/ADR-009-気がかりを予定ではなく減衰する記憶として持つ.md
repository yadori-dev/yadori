# ADR-009 気がかりを、予定ではなく減衰する記憶として持つ

| 項目 | 内容 |
|---|---|
| 状態 | 有効 |
| 決定日 | 2026-08-31 |

## 判断

宿りが自分から話しかける内容を、時刻を決めて必ず発火する「予定」として持たない。**時間とともに薄れ、解決すれば消え、繰り返し現れれば太る「気がかり」**として持つ（[ADR-005](ADR-005-記憶を減衰の速さが違う一つの仕組みとして持つ.md) の一種）。

気がかりは、会話の中と夢の中で生まれる。生まれるとき、次の三つを一緒に持つ。

- 何が気になっているか
- どのくらいの頃合いで言いたいか（時刻ではなく、状況を含む）
- 言う前に確かめたいこと

言う前に確かめる手順は、**話すかどうかの最終判定を兼ねる**。確かめた結果すでに解決していれば、その気がかりは話されずに消える。

同じ気がかりが繰り返し現れた場合、新しい件として積まず、既存の一件へまとめて強める。まとまったものは、宿りが長く引っかかっていることとして扱う。

## 理由

予定は必ず発火する。三日前に言おうと決めたことが、今日も言う価値があるとは限らない。利用者が自分で解決していることも、状況が変わっていることもある。既に終わった話を持ち出す振る舞いが、自分から話しかける機能が疎まれる最も大きな原因である。

薄れて消える形にすると、この問題が仕組みで解ける。同時に、気持ちが動いて生まれたものと、会話で生まれたものが同じ道を通るため、話しかける判定が一本で済む。

繰り返し現れる気がかりをまとめるのは、夢で生まれた気がかりが次の夢の材料になり、同じ話題で無限に増え続けるのを止めるためでもある。まとめた結果は、消すのではなく一件の強い気がかりになる。

## 受け入れる不利益

「必ず言う」を表現できない。約束したことを確実に伝える用途には向かない。

## 見直す条件

利用者が、必ず届く伝達を宿りへ求めたとき。その場合も気がかりを予定に変えず、別の概念として足すかを検討する。
