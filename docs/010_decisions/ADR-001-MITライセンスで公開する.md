# ADR-001 MITライセンスで公開する

## 判断

コードとドキュメントを[MIT License](../../LICENSE)で公開し、同じライセンスによる外部からの貢献を受け付ける。許諾条件と免責はLICENSEの原文を正典とする。同梱する依存ソフトウェアの条件は、それぞれのライセンスを維持する。

## 理由

利用者が自分の宿りを導入・改変・再配布できる状態になった。著作権表示と許諾文を残す条件で、商用を含む利用を認める短いライセンスを選ぶ。根拠は[OSI掲載のMIT原文](https://opensource.org/license/mit)。

MITはプログラムと文書の利用条件であり、利用者が保存する会話への権利をプロジェクトへ譲渡する条件ではない。会話の保存先とAIサービスへ渡る範囲は[セキュリティ方針](../../SECURITY.md)と利用ガイドで説明する。

## 不利益と見直す条件

再配布された改変版の公開は求めない。配布物には許諾文を含め、外部のコードを取り込むときはその利用条件を確認する。将来別の配布条件が必要になった場合は、既にMITで公開した部分の許諾を維持できる範囲で検討する。
