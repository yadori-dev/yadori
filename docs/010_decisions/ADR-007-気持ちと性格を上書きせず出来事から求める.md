# ADR-007 気持ちと性格を上書きせず、出来事から求める

| 項目 | 内容 |
|---|---|
| 状態 | 有効 |
| 決定日 | 2026-08-31 |

## 判断

気持ちと性格の現在値を、行を書き換える形で保存しない。**いつ、何があって、どちらへどれだけ動いたか**を出来事として積み、現在値はそこから求める。

時間による減衰は、模型に判定させず、記録された出来事と経過時間から計算で求める。模型が決めるのは「今のやりとりで何がどう動いたか」だけで、動いた後の値そのものではない。

## 理由

現在値だけを持つと、二年後に性格が意図しない方向へ寄ったとき、いつ何があってそうなったかを誰も追えず、戻せない。積んでおけば、変化の経緯がそのまま宿りの来歴になり、必要なら特定の時点へ戻せる。

減衰まで模型に任せると、値が理由なく漂う。呼ぶたびに違う判断が返るため、放っておくとすべての感情が振り切れるか、逆にまったく動かなくなる。時間で薄れる部分は計算で確定させ、模型の判断が入る範囲を「一度の出来事でどう動いたか」に閉じる。

## 受け入れる不利益

現在値の取得に計算が要るため、単純な読み出しより遅い。出来事は増え続けるので、ある時点までの値を確定して以降を積む工夫が、いずれ必要になる。

## 見直す条件

現在値の計算が、フックの応答時間の制約に収まらなくなったとき。その場合も出来事は消さず、途中の確定値を持つ形にする。
