# ADR-015 思い出しやすさを、思い出された記録から求め、並べ替えの点数に混ぜない

| 項目 | 内容 |
|---|---|
| 状態 | 有効 |
| 決定日 | 2026-08-31 |

## 判断

出来事の記憶は、**思い出しやすさ**を持つ。よく思い出す記憶ほど詳細が長く残り、めったに思い出さない記憶は薄れていく。

- 思い出しやすさは、**いつ何回思い出されたか**の記録と、経過時間から計算で求める。模型に判定させない
- 思い出すたびに強まり、放っておくと下がる。強まり方には上限を置く
- **原文は消さない。** 薄れるのは思い出しやすさだけで、名指しされれば弱った記憶も出てくる（[ADR-006](ADR-006-会話の原文を正典とし埋め込みを作り直せる索引とする.md)）
- **意味の近さと同じ点数へ混ぜない。** 近さと思い出しやすさは別々の値として持ち、両方を読める

## 理由

**記憶が増えるほど、意味の近さだけでは足りなくなる。** 二年前に一度きり出て以来触れていない話と、毎週のように話していることが、同じ重みで並ぶのは誤りである（`PB-009`）。何度も話題に出ることは詳しく残り、めったに出ないことは奥へ沈む、という差が要る。

**計算で求めるのは、[ADR-007](ADR-007-気持ちと性格を上書きせず出来事から求める.md) と同じ理由である。** 模型に「これはどれくらい覚えているか」を尋ねると、呼ぶたびに違う答えが返り、理由なく漂う。思い出された記録は事実として積めるため、そこから求める。

**混ぜない理由は、[ADR-010](ADR-010-思い出す質を評価セットで判定する.md) が測れなくなるからである。** 一つの点数へ溶かすと、ある記憶が上位に来たのが「関係あるから」なのか「よく思い出しているから」なのかを分けられない。評価セットは意味の近さを測るものであり、そこに別の要因が混ざると、条件を変えた効果を読めなくなる。直近のやりとりを別の道で渡すのと同じ判断である。

## 受け入れる不利益

思い出すたびに書き込みが発生する。また、上位に出やすい記憶ほど強まりやすいため、放置すると一部の記憶だけが際限なく強くなる。強まり方の上限で抑えるが、上限の値は測って決める必要がある。

## 見直す条件

思い出しやすさを使っても `PB-009` が改善しないと測って分かったとき。その場合も、混ぜる方向ではなく、別の値を足す方向で検討する。
