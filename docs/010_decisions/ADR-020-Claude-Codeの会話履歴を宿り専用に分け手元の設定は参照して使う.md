# ADR-020 普段の対話環境へ宿りの機能だけを加える

## 判断

Claude Code、Codex、agy の通常の設定、認証、権限、信頼確認、スキル、MCP、フック、会話履歴は各道具へ任せる。宿りは通常の設定ディレクトリを差し替えず、起動時に宿りのフックと記憶の接続だけを追加する。道具名以降の引数を渡し、終了後も道具の履歴から再開できる。

Claude Code は `--settings` と `--mcp-config` で追加する。既存の設定源と MCP を限定しない。Codex は `-c` で起動時の設定層にフックと MCP を追加する。フックの信頼確認を飛ばさず、命令は同じ内容を保ち、一回の作業状態の場所は環境変数で渡す。agy は追加ディレクトリの `.agents` へフックと MCP を置く。

`YADORI_HOME/<道具>/sessions` は宿りの未完・完了通知・検索の台帳だけを持つ。通常の設定、認証ファイル、会話履歴をここへコピーしない。正常終了後の片付けはこの作業状態に限る。記憶の原文の保存形式は変えない。

## 理由と選択肢

必要な設定だけを専用環境へ写す方法では、各道具の設定の探索・優先順・信頼判断を宿りが再実装することになり、通常の設定が使えない。未確認の MCP があるだけで会話を開始できず、履歴の再開も失われる。

通常設定を書き換えて終了時に戻す方法は、並行起動と異常終了で取り違えるため採用しない。正式な追加設定の入口を使い、判断の主体を各道具に保つ。

## 不利益と確認

普段の指示・フックと宿りの文脈が両方動く。話し方が矛盾した場合や、通常のフックが応対を続けさせる場合は影響を受ける。信頼・認証・課金方式を宿りが独自に選び直すことはしない。

設定の追加、通常のフックとの併用、履歴の保存・再開は実際の各道具で確認する。内部の要約・判定など、利用者の対話環境を持ち込まない呼び出しは [ADR-016](ADR-016-応対は対話する道具を通して作り、その道具の文脈を持ち込まない.md) の別の境界である。
