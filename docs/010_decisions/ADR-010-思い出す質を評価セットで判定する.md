# ADR-010 思い出す質を、評価セットで判定する

| 項目 | 内容 |
|---|---|
| 状態 | 有効 |
| 決定日 | 2026-08-31 |

## 判断

「関係する記憶を思い出せているか」を、文章で書いた受入基準では判定しない。**発話と、そのとき出るべき記憶の組を並べた評価セット**を正典とし、そこに対する測定結果で判定する。

評価セットの各件は次を持つ。

- 話しかけられた文章
- そのとき上位に出るべき記憶
- 出てはいけない記憶（あれば）

判定に使う値は、期待した記憶が上位何件目までに入るか、無関係な記憶がどれだけ混ざるか、の二つである。閾値、件数、並べ替えを変えるたびにこれを測り、良くなった点と悪くなった点を両方記録する。

測る対象は、意味の近さで探す側だけである。直近のやりとりは意味を見ずに常に渡すため、評価セットでは測らない。二つを混ぜて並べると、思い出せた理由が近さなのか新しさなのか分けられず、条件を変えた効果を読めなくなる。

評価セットの内容は架空の会話で作る。利用者の実際の会話をリポジトリへ入れない。

## 理由

思い出す質は、この道具の中心でありながら、外から見た振る舞いを文章で書けない唯一の部分である。「ちゃんと思い出せている」は第三者が判定できず、そのまま受入基準にすると、中心が無検査のまま進む。

閾値を緩めれば無関係な記憶が会話へ混ざり、締めれば必要なときに出てこない。この調整は感覚では追えず、変更のたびに何が良くなり何が悪くなったかを測らないと、前より悪い状態へ進んでいることに気づけない。

## 受け入れる不利益

評価セットを作り、育てる手間がかかる。また、架空の会話で測るため、実際の利用での感覚と一致しない場合がある。

## 見直す条件

評価セットの結果が良いのに実際の会話では思い出せない、という食い違いが繰り返し起きたとき。そのときは評価セットの作り方を見直す。測定をやめる方向へは戻さない。
